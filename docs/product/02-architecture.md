# 架构设计与模块划分

> 本文档描述产品目标与方案，不代表当前实现状态；实现细节见 SPEC，现状见 Current。

## 架构总览

TodoList 是单机 Windows 桌面应用：Tauri 2 外壳承载 Rust 核心与 React / TypeScript 界面，界面保持薄层，数据与业务语义集中在 Rust 侧。应用启动后直接读写用户数据目录，不设隐藏任务数据库。

数据形态以一个数据目录为中心：每个清单对应一个 YAML 文件，任务数据与应用设置分离存放。

外部协作是架构的一等约束：外部程序、git、网盘与 agent 均可直接修改任务文件；应用写回时保留未知字段与稳定标识。Agent 协助作为受控子系统运行，只在用户启用时联网，读取范围限于任务关联材料，结果写入独立目录。

## 关键架构约束

- **单模块产品**：全部产品能力由 10-app 承载，不拆分为独立服务或子模块。
- **文件优先**：YAML 任务文件是唯一事实源，应用不得引入隐藏数据库或不可见缓存作为权威数据。
- **外部写入共存**：架构必须容忍应用之外的写入者，写回不得丢失未知字段与稳定 ID。
- **平台限定**：Windows 10/11 + WebView2，不做 macOS / Linux 适配。
- **联网受控**：只有用户显式启用的 Agent 协助可以联网，默认离线。
