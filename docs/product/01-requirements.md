# 产品需求

> 本文档描述产品目标与方案，不代表当前实现状态；实现细节见 SPEC，现状见 Current。

## 能力地图

### 清单与任务

- **清单管理** — 创建、重命名、删除与排序多个清单；每个清单对应数据目录中的一个 YAML 文件（`FR-APP-01`）。
- **任务基础** — 新建、编辑标题与备注、完成 / 取消完成、删除；操作即时写回文件（`FR-APP-02`）。
- **子任务** — 任务下一层分解，可独立勾选与改名；任务行显示完成进度（`FR-APP-03`）。
- **排序与跨清单移动** — 拖拽调整任务顺序，或把任务移动到另一个清单；稳定 ID 与未知字段保持不变（`FR-APP-04`）。
- **已完成视图** — 聚合各清单的已完成任务，按来源分组并支持折叠与恢复（`FR-APP-18`）。
- **删除回收站** — 删除的任务与清单先进入「已删除」，24 小时内可恢复，也可在回收站中提前彻底删除；到期自动永久删除（`FR-APP-37`）。

### 组织与时间

- **标签与过滤** — 为任务打标签，并按标签筛选（`FR-APP-05`）。
- **优先级** — 在任务详情设置高 / 中 / 低优先级或清除（`FR-APP-06`）。
- **截止日期与时间** — 设置可选具体时间的截止日期，并支持清除（`FR-APP-07`）。
- **提醒** — 对未完成任务在截止前与截止时刻发送系统通知，可关闭提醒（`FR-APP-08`）。
- **重复任务** — 按规则在完成后生成下一实例（`FR-APP-09`）。
- **逾期标识** — 已过截止时间且未完成的任务获得视觉标识（`FR-APP-10`）。

### 检索与视图

- **搜索** — 按标题、备注或标签即时过滤，并定位到所属清单（`FR-APP-11`）。
- **智能过滤** — 今天 / 即将 / 全部 / 已完成等视图过滤，不改写文件（`FR-APP-12`）。
- **排序视图** — 按截止时间、优先级或创建时间查看，不改变文件内数组顺序（`FR-APP-13`）。

### 桌面集成与外观

- **托盘常驻** — 关闭主窗后保留托盘入口，可快速查看或添加任务（`FR-APP-14`）。
- **全局快捷键** — 通过快捷键呼出快速添加（`FR-APP-15`）。
- **开机自启** — 由设置开关控制是否随系统启动（`FR-APP-16`）。
- **深色模式** — 亮色 / 暗色 / 跟随系统，偏好重启后保持（`FR-APP-17`）。

### 文件与外部协作

- **文件即事实源** — 应用直接读写 YAML，不设隐藏任务数据库（`FR-APP-19`）。
- **外部写入可见** — 外部修改文件后，应用自动重载并反映变化（`FR-APP-20`）。
- **agent 友好契约** — 稳定 ULID、未知字段宽容、可预测的写入语义（`FR-APP-21`）。

### 应用功能栏与便签

- **应用功能栏** — 承载应用级动作与配置入口；宽屏竖栏、窄屏横排，入口顺序可调（`FR-APP-22` ~ `FR-APP-24`）。
- **便签** — 从功能栏呼出独立速记窗口，可多开、随主题换色，关闭即丢弃（`FR-APP-35`）。

### Agent 协助

- **Provider 与凭据** — 内置多家预设或自定义端点；密钥存本机受保护存储，不回界面（`FR-APP-25`）。
- **任务级启用与关联** — 为任务关联文件 / 目录，显式启用协助；关联不等于授权（`FR-APP-26` ~ `FR-APP-28`）。
- **只读研究与限额** — 只读沙箱、无命令执行；单次与单次运行读取均有上限（`FR-APP-29`）。
- **调度与手动控制** — 仅应用运行时按夜间时间窗调度；支持立即执行、重跑与停止（`FR-APP-30` ~ `FR-APP-32`）。
- **结果与历史** — 报告与来源写入独立结果目录，运行历史可查（`FR-APP-33` ~ `FR-APP-34`）。

## 关键行为

- **操作即时写回** — 任务与清单的变更立即落盘，不经过隐藏数据库或草稿态。
- **视图只读** — 搜索、过滤与排序只改变展示，不改写文件内容或数组顺序。
- **外部写入宽容** — 应用重新读取外部修改并展示变化；写回保留稳定 ID 与未知字段。
- **提醒只覆盖未完成任务** — 完成、删除或关闭提醒后不再发送通知。
- **删除可恢复（24 小时）** — 任务与清单删除先进入回收站，可单项恢复或提前彻底删除；超过 24 小时自动永久删除，关闭应用期间的过期在下次启动时清理。
- **关联不等于授权** — Agent 协助需用户显式启用；默认离线，联网范围受任务级关联材料限制。
- **便签不持久化** — 关闭便签或退出应用即丢弃内容，不进入任务数据。

## 非目标

- 账号体系与内置云同步；多设备同步由用户自行通过 git / 网盘完成。
- 非 Windows 平台。
- 内置备份与撤销历史（删除仅有 24 小时回收站，不是备份 / 历史版本）。
- Agent 执行任意命令、修改源文件，或在用户未启用时联网。

## 关键产品约束

- 本地优先：任务数据以 YAML 纯文本为唯一事实源，应用不引入隐藏数据库。
- 数据目录可被外部程序、git 与网盘直接管理；应用必须容忍并保留未知字段。
- 联网仅限用户显式启用的 Agent 协助；默认离线，费用与发送内容由用户承担。
- 单机本地形态：Windows 10/11 + WebView2，无账号依赖。
