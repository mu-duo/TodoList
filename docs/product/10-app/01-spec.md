# 10-app 功能规格

> 定位：10-app 目标态功能规格（FR-APP-NN，逐条给验收判据）。依据：相关 ADR（0001~0010）。

## 1. 清单与任务

| FR | 功能 | 验收判据 |
| :--- | :--- | :--- |
| FR-APP-01 | 清单管理：多清单，创建 / 重命名 / 删除 / 排序 | 侧栏操作后 `lists/` 下文件同步创建 / 改名 / 删除，`order` 写入；重启后状态保持 |
| FR-APP-02 | 任务基础：新建 / 编辑（标题、备注）/ 删除 / 完成与取消 | 操作即时写回文件；**新建任务插入清单首位**（`tasks[0]`）；done 带 `completed` 时间，取消后恢复 open 且移除该字段（**1.7.0 增强（已验收 2026-10-14）**：任务行内编辑——宽屏双击内容区 / 右键菜单「编辑」（全宽度、普通 + 已完成行）；光标置尾、Enter 提交 / Esc 取消 / 失焦提交；空 / 纯空白还原原值） |
| FR-APP-03 | 子任务：一层分解，独立勾选 | 子任务状态独立持久化（已实现）；父任务显示子任务进度（**已实现**：任务行尾 `已完成/总数`，悬停换成删除按钮；触屏并排、计数在 `×` 左侧） |
| FR-APP-04 | 拖拽排序与跨清单移动 | 拖拽后文件内 tasks 数组顺序同步；跨清单移动后原文件移除、目标文件出现（id 不变）（**已实现**：跨清单转移＝右键「移动到清单 ▸」+ 拖拽到「清单条」；Value 级移动保留 id 与全部未知字段；仅普通视图可拖拽、已完成视图只读；**用户验收通过 2026-10-13**） |
| FR-APP-37 | 删除回收站：任务 / 清单移入「已删除」，24 小时内可恢复 | 删除任务＝从原清单移除并写入 `lists/.trash.yaml`（保留任务全部字段 + 原清单文件名 / 显示名 + 删除时间）；删除清单＝整份清单移入保留文件、原文件消失。侧栏「已删除」固定入口（与「已完成」同级、不可重命名 / 排序 / 普通删除）按来源清单分组，任务行**外宽与普通任务卡一致**、右侧固定剩余时间与「恢复」（窄屏也不换行）；点击任务行打开**只读**详情（恢复后可编辑）；任务行右键「彻底删除」经确认后立即真删除。来源清单分组可折叠（除无时间标签外与「已完成」一致），折叠集合存 `settings.yaml` 的 `trash.collapsed`。**已删除的清单**行同样支持右键「彻底删除」（经确认后连同其中任务立即永久删除）。恢复任务回原清单末尾；原清单不存在时提示选择目标清单；同 id 冲突报错不写盘。恢复清单重建文件，文件名冲突自动改用不冲突名。`deleted + 24h ≤ now` 自动真删除；应用启动、运行中每 10 分钟、每次读取回收站时清理；无法解析删除时间的条目保留。回收站空则删除保留文件 |

**回收站语义（FR-APP-37）**：删除是「移动」而不是物理抹除；保留 24 小时，属于防误删窗口而非备份 / 历史版本（ADR-0010）。子任务删除不进入回收站。保留文件是数据目录内的普通 YAML（外部可读可改），但**不是清单**：清单加载、排序与新建示例清单都跳过它；未知字段宽容保留。删除 / 恢复为跨文件写：删除先写回收站再移除原位置，失败回滚回收站；恢复先写目标再移除回收站条目，回收站写失败回滚目标。`deleted` 为本地时间 `YYYY-MM-DDTHH:MM:SS`；外部写入无法解析的时间视为保留。

## 3. 时间

| FR | 功能 | 验收判据 |
| :--- | :--- | :--- |
| FR-APP-08 | 提醒：默认三档 + 到期（可「不再提醒」） | 仅 open 任务参与；默认在 due 前 7 天 / 1 天 / 1 小时及 due 时刻尝试系统通知；任务详情勾选框与通知上的「不再提醒」为同一开关（任务 YAML `reminder: false`）（**1.6.0 已实现并本地验证**：四档默认开启；通知按钮仅在通知停留屏幕时可点（Windows Tier 1 限制）；点通知本体前置窗口） |
| FR-APP-09 | 重复任务（规则字段于该切片定稿） | 完成任务后按规则生成下一实例；不重复、不丢失 |
| FR-APP-10 | 逾期高亮 | 过 due 且未完成任务有标识；完成或改期后消失 |

**提醒语义（FR-APP-08，1.6.0 已实现并本地验证）**：默认对带 `due` 的 open 任务在 4 个档位尝试提醒：due 前 7 个本地日历日 / 前 1 个本地日历日 / 前 1 小时（本地墙钟减 1 小时）与 due 时刻；纯日期 due 当地 09:00，date-time 使用指定时刻；`reminder: false` 关闭（缺省开启；旧 `reminder_offset_days` 视同开启、元数据保存时移除）。夏令时不存在的当地时刻顺延至下一有效分钟，重复时刻取 earliest。启动与手动刷新同步任务快照；运行时单 worker 定时，最多每 60 秒重新校时；无文件 watcher。首帧（新建 / 改 due / 升级 / 关闭后再开启）静默 claim 已过的提前档、不发通知；首帧已过的「到期档」补一条；完成→重开（观察到非 open→open）静默 claim 全部已过档（含到期档）、只保留未来档。运行中错过的档按 task 合并一条（due 已过→「已到截止时间」，否则按真实剩余时长），并 claim 本次全部已过档；未来事件继续排程。due 变更按 `task_id + canonical due + event type` 形成新 key；done / delete 取消提醒。

提醒仅根据完整快照运行：清单目录/文件读取错误、无效 YAML 根节点或 `tasks` 结构、被跳过的任务项等会使快照不完整；即使成功读取的清单仍可展示，提醒也会全局 fail closed 暂停，不发送、不更新或清理状态 checkpoint。完整 `load_lists` 刷新成功后恢复；读盘与 worker ack 串行。ledger 在同一文件持久化 `attempted` event keys、`observed: { task_id: canonical due }`（首帧标记）与 `last_status: { task_id: bool }`（仅完整快照中的唯一 ID；`true=open`，`false=非 open`）。跨重启观察到 done→open 时，先原子 claim 该任务当前全部逾期未尝试事件（含到期档）、只保留未来未试事件，再 reconcile。应用关闭期间完整发生的 open→done→open 无法识别；按已确认语义，启动按最终 open 状态做普通 catch-up。

主窗最小化时运行；「关闭时最小化到托盘」开启（默认）时点关闭隐藏到托盘、进程保活（退出走托盘菜单；设置关闭时关闭主窗即退出进程）。Windows toast 为 best effort；plugin permission API 无法探测 Windows 通知设置 / 专注助手等系统抑制，`show` 成功不代表用户实际看到；通知带「不再提醒」动作按钮，但点击仅在通知停留屏幕时被接收（进入通知中心 / 应用退出后点击无响应——Tier 1 限制，已接受）；点通知本体＝显示并聚焦主窗口。账本只记录本机发送尝试，不是送达回执；当前无 UI 状态面板。

| FR | 功能 | 验收判据 |

**已完成视图分层语义（FR-APP-36，叠加在 FR-APP-18 之上）**：时间基准为完成时间 `completed`——今天＝本地自然日 00:00 起；七天内＝昨天至第 7 天前（不含今天）；更早＝第 8 天前及更早；缺失或无法解析的时间戳归「更早」。跨天只在进入已完成视图或数据刷新时懒重算，不加午夜定时器。层级为 来源清单分组（可折叠，沿用 FR-APP-18）＞ 时间标签（不可折叠，说明性小标签）。空时间组隐藏；某清单无可见任务时整组不渲染。计数（侧栏「已完成」总数、组头「名称 · 数量」）只统计当前渲染的可见项。开关打开时归档项仍归入其 `completed` 所属时间组，排在组内未归档项之后（组内各自 `completed` 倒序），以弱化样式 + 「已归档」角标区分，不另设「已归档」分组。任务与清单右键菜单按区划分隔，「删除」独立成区（契约见 [02-interfaces.md](02-interfaces.md) §5.4）。

## 8. 应用功能栏（App Bar）

> 术语：应用功能栏 / 动作入口 / 配置入口（见 `CONTEXT.md`）。承载应用级即时动作与功能配置入口，不承担清单导航，名称不随横向 / 纵向呈现而改变。
> **状态（2026-10-12）：已实现（FR-APP-22~24）**，行为按下方验收判据落地、**用户验收通过**（见 [10-app 现状](../../current/app.md)）；本轮不实现 Agent 入口，也不放占位。

| FR | 功能 | 验收判据 |
| :--- | :--- | :--- |
| FR-APP-22 | 应用功能栏位置与呈现 | 窄屏（≤760px）保持现有顶部位置；宽屏（>760px）为**独立最左竖栏**；两种形态均保留现有主区与详情栏、**不新增清单侧栏**；栏宽 = 按钮点击区 + 留白（约 40–48px），图标约 16px；入口图标**无常驻文字**、悬浮显示中文名称、保留 aria 名称 |
| FR-APP-23 | 应用功能栏入口行为 | 动作入口点击即执行或切换（刷新 = **只重扫重读清单**；置顶 = 切换并反映启用态，保持既有置顶锁定尺寸语义）；配置入口打开**自定义模态**（保留焦点 / Esc / 遮罩规则）；功能栏层级**不越过模态 / 抽屉**；入口忙碌时禁用并给出反馈 |
| FR-APP-24 | 应用功能栏入口顺序 | 入口**连续排列、无上下分组**；默认顺序 刷新 → 置顶 → 便签 → 设置 → Agent；宽窄**共用同一顺序**，存现有 `settings.yaml`（本机偏好，**不写清单**）；稳定入口 id、重复取第一次、未知入口隐藏且保留原槽位（仅重排可见入口）；新增未配置入口默认追加到用户顺序末尾、用户重排后保存；恢复默认清除历史顺序（含未知入口）；排序放下即原子保存，失败回滚到最后成功顺序并报错 |

**细则**：

- **默认顺序**：刷新 → 置顶 → 便签 → 设置 → Agent（Agent 于 1.7.0 追加、便签于 1.8.0 加入；新增入口对已保存顺序仍默认追加到末尾）。
- **拖拽**：鼠标超过阈值触发拖拽，触屏长按触发；**拖拽结束不触发点击**。
- **排序交互**：窄屏顶部溢出进入「更多」菜单（**不挤压标题、不产生整页横向滚动**）；设置提供**全部可用入口**的完整排序（拖拽 / 上移 / 下移 / 恢复默认）。
- **刷新语义**：只重扫重读清单文件，**不保存 / 覆盖正在编辑的详情草稿、不重读设置、不新增文件监听**。
- **断点**：沿用现有 760px 断点（窄 ≤760px / 宽 >760px）；**已复核临界宽度附近（约 761px）**的栏位与图标呈现（见 [10-app 现状](../../current/app.md)）。
- **配置契约**：顺序字段与读写语义见 [02-interfaces.md](02-interfaces.md) §5（实际契约）。

| FR-APP-28 | 只读安全沙箱 | 只读访问、**不执行命令**、**不修改源文件**；阻止常见敏感文件 / `.git` / 应用密钥；**防链接越界**（链接不逃逸授权范围）；首次启用**告知云端发送边界** |
| FR-APP-29 | 读取计量 | 单次**文本**读取 ≤**256 KiB**、单次运行累计 ≤**5 MiB**；目录 / 文件**分页**、累计**不可绕过**（ADR-0007）；**不缩小授权范围**；不可解析资料**明确列出遗漏项并继续研究**（**不承诺全格式**） |
| FR-APP-30 | 调度与时间窗 | 仅**应用运行时**调度（**不新增托盘 / 自启 / 唤醒**）；本地时间 **00:00（含）–09:00（不含）** 启动，已启动可跨界完成；**09:00 后不再启动**；清单 / 任务按**显示顺序**处理 |
| FR-APP-31 | 执行上限与失败 | 并发 **1**、单次运行最长 **30 分钟**；**模型 / 搜索调用次数不设上限**；每 run 主循环**步数护栏上限 40**（**防失控护栏、非调用次数帽、不计入预算 / 次数统计口径**），达上限 → `failed(StepLimit)` 不重试，实际步数记入运行记录 `stats.steps`；每夜（**含首次**）最多 **3 次尝试**，仅对**临时网络 / 429 / 服务端失败**退避重试；**失败退避不阻塞其它任务**；**Key 余额 / 权限 / 配置错误→停止**；中断（非成功）**保留部分结果** |
| FR-APP-32 | 手动控制 | 子菜单提供「**立即 / 重跑**」（**绕过夜间窗口**）与「**停止**」；**手动停止不自动重试**，需显式「重新执行」；**停用或完成任务→取消当前并禁止后续调度**；停用再启用时**未成功任务入队**、**已成功仍不自动重跑** |
| FR-APP-33 | 成果与历史 | 成果输出到用户配置**主目录** / 任务 **ULID** / **时间**（+ **运行 ID**）；**独立历史**（稳定 id）；`report.md` 记录**来源清单 / 运行摘要**；详情可**查看结果**与「**打开结果目录**」 |
| FR-APP-34 | 状态与呈现 | 任务行尾**机器人图标位于 count 左侧且悬停不消失**；点详情进入 Agent 区（状态历史）；颜色：**待执行中性 / 运行靛蓝（轻忙碌）/ 成功绿 / 失败红 / 停止中性**；**停用隐藏图标但保留历史** |

**细则**：

- **步数护栏（FR-APP-31）**：每 run 主循环步数上限 **40**（`MAX_STEPS`）——**防失控护栏**，**不是调用次数帽、不参与预算 / 次数统计口径**；达到即 `failed(StepLimit)`、**不重试**；实际步数写入运行记录 `stats.steps`。
- **停止语义（FR-APP-32）**：手动停止 → **本夜不再自动重排**、需显式「重新执行」；停用 / 完成 / 删除导致的停止与手动停止**可区分**（运行记录 `stop_reason`）；停用→再启用时**未成功任务可重新入队**；**已完成任务不入队**。
- **运行记录与结果（FR-APP-33）**：结果布局 `{result_root}\{task_id}\{时间戳}_{run_id}\`，含 `report.md` + `sources.json`；运行记录本机 `%APPDATA%\com.lftan.todolist\agent\runs\{run_id}.json`；结果目录**只能由记录推导**。
- **读取限制**：仍为 ADR-0007（单次文本 ≤256KiB、运行累计 ≤5MiB、分页不可绕）。
- **多 Provider（FR-APP-25）**：内置 9 预设（openai / deepseek / anthropic / opencode-go / openrouter / gemini / qwen / zhipu / kimi）+ 自定义端点（协议可选、key 可空）；双协议（Anthropic Messages 兼容 / OpenAI Chat Completions 兼容）；`agent.provider` 缺失默认 deepseek、未知 **fail closed**；**搜索能力按 provider 声明降级**（仅声明支持者启用并下发 `native_search`，其余 UI 标注）；模型列表失败 / 不支持回退自由输入；依据 **ADR-0009**（修订 ADR-0005/0008 的 provider 限定）。

**注**：Agent 入口位于应用功能栏、默认追加在顺序末尾（见 §8）。

## 10. 便签（FR-APP-35，**1.8.0 已实现；用户验收通过 2026-10-16**）

> 术语「便签」见 `CONTEXT.md`：自由速记窗口，不参与任务数据、不持久化，关闭即丢弃。

| FR | 功能 | 验收判据 |
| :--- | :--- | :--- |
| FR-APP-35 | 便签（独立速记窗口） | App Bar 动作入口「便签」点击一次新建一个独立窗口（无复用、无上限）；颜色与主题联动（亮色 = 浅色系 黄 / 白 / 绿 / 蓝 / 青 / 紫，暗色 = 灰 → 灰白 6 度；按开窗序轮换、主题切换按档位实时重映射）；无边框、进入任务栏分组（悬浮缩略图可见；Alt-Tab 本就包含）、默认 280×320、可鼠标缩放（最小 200×160）、双击顶部不最大化、文本区与按钮外可拖动、从任务栏缩略图激活后自动聚焦文本区；多行纯文本（自动聚焦、无 placeholder、无限制、溢出滚动）；pin = 系统级置顶开关（默认关、可切换）；close 及一切关闭路径均丢弃内容、无提示、不持久化；**关闭应用时若存在便签需确认**（关窗 → 应用内确认框；托盘「退出」→ 系统原生对话框），确认后全部便签一并关闭并退出；与任务数据零联动 |

**细则**：

- **窗口契约**：URL `/?note=<index>&theme=<pref>`；标签 `note-<n>`；创建即带 `theme`（首帧不闪色）；主题变更经事件 `theme-pref-changed` 实时重映射；契约细节见 [02-interfaces.md](02-interfaces.md) §8。
- **退出语义**：关窗（托盘设置关闭时）存在便签 → `prevent_close` + 应用内确认框（事件 `exit-requested-with-notes` / 命令 `exit_app`）；托盘菜单「退出」存在便签 → 系统原生非阻塞对话框（不恢复主窗、防连点）；托盘设置开启时关窗仍为隐藏到托盘（便签保留）。
- **已知取舍**：暗色灰阶避开中灰带（#60–#98 双向对比度受限），呈「3 深灰 + 3 浅灰」两族；原生退出对话框失败不可同步感知（底层丢弃错误，记档）。
- **2026-10-19 调整**：便签进入任务栏分组（取消 `skipTaskbar`）——任务栏悬浮缩略图与窗口列表可见；缩略图 X / 任务栏「关闭窗口」= 静默关闭丢弃；从缩略图激活自动聚焦文本区；托盘开启且便签存在时任务栏图标不消失（方案 A 刻意）。
