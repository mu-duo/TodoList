# 10-app 模块

> 本文档描述产品目标与方案，不代表当前实现状态；实现细节见 SPEC，现状见 Current。

## 这个模块让谁做什么

10-app 是 TodoList 的桌面应用本体，为使用者提供完整的待办工作台，也为外部 agent 提供稳定的文件协作界面。应用承载全部产品功能，并把任务数据组织成用户数据目录下的 YAML 文件；它不替代用户的版本管理或同步工具。

## 关键行为

- **清单与任务工作台** — 多清单管理、任务增删改、完成与恢复、子任务分解、拖拽排序与跨清单移动；所有变更即时写回文件。
- **组织与时间** — 标签、优先级、截止日期、提醒、重复任务与逾期标识；提醒只覆盖未完成任务。
- **检索与视图** — 搜索、智能过滤与排序视图；视图操作不改变文件内容。
- **桌面集成与外观** — 托盘常驻、全局快捷键、开机自启与亮 / 暗 / 跟随系统主题。
- **文件契约** — 数据目录、清单 YAML schema、稳定 ULID、未知字段宽容、原子写与外部写入语义，构成应用与外部 agent 的共同依据。
- **应用功能栏** — 应用级动作与配置入口的统一承载区；宽屏竖栏、窄屏横排，顺序可调并跨形态共享。
- **Agent 协助** — 用户选择 Provider 并显式启用后，agent 只读关联材料、按夜间窗口或手动运行，并把报告写入独立结果目录；默认不联网、不自动付费。
- **便签** — 从功能栏呼出独立速记窗口，可多开且不持久化，与任务数据零联动。

## 边界

| 负责 | 不负责 |
| :--- | :--- |
| 全部产品功能、桌面交互与数据目录 / 清单文件契约 | 账号体系、内置云同步与多设备同步（由用户经 git / 网盘自理） |
| 外部写入的读取、容错、未知字段保留与写回语义 | agent 进程本身的能力实现（信息收集、自动完成等属外部） |
| Agent 协助的配置、只读沙箱、调度与结果落盘 | 非 Windows 平台适配 |
| 应用功能栏、托盘、便签等桌面集成 | v1 内置长期备份与撤销历史（删除仅有 24 小时回收站） |

## 非目标

- 不做账号、云端任务存储或跨设备同步服务。
- 不做 macOS / Linux 版本。
- 不允许 Agent 执行命令、修改源文件或在未启用时联网。
