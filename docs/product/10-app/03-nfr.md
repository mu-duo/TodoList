# 10-app 非功能规格

> 定位：10-app 的非功能约束。

## 1. 平台与运行

- Windows 10/11（依赖 WebView2），仅桌面；Tauri 2 稳定线。
- 判据：目标系统可启动、可重复启动；单实例运行（重复启动唤醒既有窗口，桌面集成切片落地）。

## 2. 本地性与隐私

- 除用户自行配置的同步 / git 外不发起网络请求；无账号体系。
  - 例外：**Agent 协助**为**受控**网络出口（仅用户显式启用；provider 为预设官方端点或用户自定义端点，见 §6 与 ADR-0008、ADR-0009）。
- 判据：断网环境下全部本地功能可用（Agent 除外，Agent 断网时其联网步骤失败且不影响其它功能）。

## 3. 数据安全

- 写入原子化（临时文件 + rename），避免半写文件。
- 未知字段保留；未知内容不因应用写入而丢失。
- v1 无内置备份：依赖数据目录纳入 git / 网盘（文档建议）。
- 判据：写入中途中断（进程被杀）后文件仍可完整解析（旧版或新版）；含自定义字段的文件往返后字段保留。

## 4. 性能

- 目标规模：个人级（单清单 ≤ 2000 任务、≤ 50 清单）。
- 判据：该规模下启动加载 < 2s（本地 SSD）、勾选操作反馈 < 100ms。
- 骨架阶段以正确性优先；性能不达标再优化（记录于 [10-app 现状](../../current/app.md)）。

## 5. 可维护性

- 数据 / 文件 / 冲突逻辑全在 Rust 侧；前端为薄层（IPC + 事件推送）。
- 判据：任务数据逻辑在 JS/TS 侧无第二实现。

## 6. Agent 协助安全（**规范已落地；隔离复验通过；真实联网未实测**）

> **状态（2026-10-14）：多 Provider 已实现**（9 内置预设 + 自定义端点、双协议、动态模型列表、搜索按 provider 降级；**ADR-0009** 修订 ADR-0005/0008 的 provider 限定）——以下约束**已在实现中落地**；**已通过隔离集成复验（假 provider、零真实网络）；用户验收通过（2026-10-14）；真实联网仍未实测**。

- **凭据保护**：密钥经 Windows **DPAPI** 加密、独立本机文件；仅内存解密；**绝不回 JS / 日志 / 错误串**（presence 仅返回布尔）。
- **无执行能力**：只读沙箱——工具面仅「只读文件」+「服务端 search」，**无 exec / shell / spawn**；修改源文件在能力上不存在。
- **只读授权边界**：open-first（从句柄读、最终路径比对授权根；**不 canonicalize 后再 open**）以收敛 TOCTOU；接受盘符路径与 **UNC 路径**（`\\server\share\...`，含 WSL 的 `\\wsl.localhost\` / `\\wsl$\`），拒绝**设备命名空间**（`\\?\` / `\\.\`）、`//` 写法、**共享根 / 盘符根**作为授权根、相对路径（含 `/home`、`/mnt/c` 这类 WSL 内部路径）、ADS、结尾点空格、保留设备名；默认阻止敏感文件与 `.git` / `.ssh` / 密钥等；防链接（reparse / junction / symlink）越界。批量添加材料为**全有或全无**，失败时报错**点名**具体路径。
- **输出目录安全**：结果路径全部由 Rust 拼装（校验 `result_root` + ULID + 时间戳），结果与源目录分离写；防 reparse / junction 替换；`open_result_dir` 只取 `runId`、拒绝任意路径参数。
- **读取限额**：单次文本 ≤256KiB、单次运行累计 ≤5MiB（分页、不可绕，ADR-0007）。
- **网络边界**：仅 Agent 功能、仅用户启用时联网；端点由**内置预设 / 用户自定义端点**提供；**禁跟随重定向**；2xx 无结果块不得判成功；结果视为不可信输入；**搜索按 provider 声明门控**；**keyless 自定义端点无认证头**；模型列表失败一律 `{source:"none"}`。
- 判据：以上约束**已随实现落地**并**通过隔离集成复验（假 provider、零真实网络）**；**用户验收通过（2026-10-14）；真实联网仍未实测**（见 [10-app 现状](../../current/app.md) / ADR-0008、ADR-0009「未实测限制」）。
