# TodoList

> 本文档描述产品目标与方案，不代表当前实现状态；实现细节见 SPEC，现状见 Current。

## 一句话

TodoList 是面向 Windows 桌面的本地优先待办工具：任务以人类可读、外部可写、可版本化的 YAML 纯文本文件为唯一事实源，同时服务使用者与外部 agent。

## 项目说明

待办数据被困在封闭应用或隐藏数据库里时，用户难以直接查看、脚本化处理、纳入版本管理，外部 agent 也难以安全读写。TodoList 要让任务数据回归普通文件：应用负责提供顺手的桌面交互，文件本身保持透明、稳定与可移植。

产品由应用与文件契约两部分构成。应用提供清单、任务、子任务、排序、提醒、检索、托盘常驻等桌面能力；数据目录中的 YAML 文件是唯一事实源，应用不引入隐藏数据库。外部程序、git 与网盘可以直接管理这些文件，应用重新读取后展示变化，写回时保留未知字段与稳定 ID。

联网仅用于用户显式启用的 Agent 协助：agent 在只读沙箱内研究用户关联的本地材料，按夜间时间窗或手动触发运行，并把报告写入独立结果目录。默认离线，费用与发送内容由用户承担。

产品保持单机本地形态：面向 Windows 10/11 + WebView2，无账号体系，不内置云同步或备份；多设备同步由用户自行通过 git / 网盘完成。

## 目标用户与问题

- **注重数据掌控的个人用户** — 不希望任务被锁进封闭应用或隐藏数据库，希望能直接查看、备份、脚本化处理并纳入版本管理。
- **用编辑器 / 脚本 / git 管理任务的高级用户** — 需要在应用之外修改任务文件，并确信应用能感知变化且不丢失未知字段。
- **外部 agent 与工具作者** — 需要一个稳定、可预测的文件契约与稳定 ID，以便安全读写任务数据而不破坏应用状态。

## 典型应用场景

1. **日常清单与任务** — 用户建立多个清单，快速添加任务，勾选完成，拆分子任务；通过拖拽排序与跨清单移动保持组织；在「已完成」视图中回顾并恢复任务。
2. **外部文件协作** — 用户用编辑器、脚本、git 或网盘直接修改任务文件；应用重新读取后展示变化，写回时保留未知字段与稳定 ID。
3. **提醒与桌面常驻** — 用户为任务设置截止时间，应用在关键时点发出系统提醒；关闭主窗后可留在托盘，需要时快速恢复。
4. **Agent 协助** — 用户为任务关联本地材料并启用协助；agent 在只读沙箱内研究材料、按计划运行，并把报告写回独立结果目录。
5. **随手便签** — 用户从应用功能栏呼出独立速记窗口，记录临时内容；关闭即丢弃，不进入任务数据。
