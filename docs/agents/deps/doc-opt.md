# 回退：doc-opt

> 当需要调用 `doc-opt` 但环境未安装该 skill 时，按本文执行。

> doc-opt 随包附带于 `skills/doc-opt`（完整版）。

对**指定的** markdown 文档做后置润色：读整篇文档，在不改变原意的前提下提升清晰度与结构；只改被点名的文件，绝不扫全仓。

## 步骤

1. **读整篇**：标出 frontmatter 与代码块——它们必须逐字节不变。
2. **计划结构改动**（删小节、重排、合并图）：先出计划，等确认再动手。
3. **改写**：按「风格 → 图 → 引用」的顺序。删无信息的冗词（其实、值得注意的是、说白了、basically、actually 等）；短句、主动语态、动词优于名词化；枚举内容用列表/表格；术语保持精确。
4. **自检**：确认无冗词残留、无裸数字引用（`[1]`）、无遗留 ASCII 图；每个 mermaid 块有声明行与闭合围栏。
5. **报告**：文件、改动类别、`待补充来源`、自检证据。

引用必须可跳转（同文档 `#anchor`、仓库内相对路径、或完整 URL），否则把来源写进句内。
