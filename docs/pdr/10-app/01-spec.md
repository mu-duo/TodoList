# 10-app 功能规格

> 定位：10-app 目标态功能规格（FR-APP-NN，逐条给验收判据）。依据：相关 ADR（0001~0008）。

## 1. 清单与任务

| FR | 功能 | 验收判据 |
| :--- | :--- | :--- |
| FR-APP-01 | 清单管理：多清单，创建 / 重命名 / 删除 / 排序 | 侧栏操作后 `lists/` 下文件同步创建 / 改名 / 删除，`order` 写入；重启后状态保持 |
| FR-APP-02 | 任务基础：新建 / 编辑（标题、备注）/ 删除 / 完成与取消 | 操作即时写回文件；done 带 `completed` 时间，取消后恢复 open 且移除该字段 |
| FR-APP-03 | 子任务：一层分解，独立勾选 | 子任务状态独立持久化（已实现）；父任务显示子任务进度（**已实现**：任务行尾 `已完成/总数`，悬停换成删除按钮；触屏并排、计数在 `×` 左侧） |
| FR-APP-04 | 拖拽排序与跨清单移动 | 拖拽后文件内 tasks 数组顺序同步；跨清单移动后原文件移除、目标文件出现（id 不变） |

## 8. 应用功能栏（App Bar）

> 术语：应用功能栏 / 动作入口 / 配置入口（见 [CONTEXT.md](../../../CONTEXT.md)）。承载应用级即时动作与功能配置入口，不承担清单导航，名称不随横向 / 纵向呈现而改变。
> **状态（2026-10-12）：已实现（FR-APP-22~24）**，行为按下方验收判据落地、**用户验收通过**（见 [04-current.md](04-current.md)）；本轮不实现 Agent 入口，也不放占位。

| FR | 功能 | 验收判据 |
| :--- | :--- | :--- |
| FR-APP-22 | 应用功能栏位置与呈现 | 窄屏（≤760px）保持现有顶部位置；宽屏（>760px）为**独立最左竖栏**；两种形态均保留现有主区与详情栏、**不新增清单侧栏**；栏宽 = 按钮点击区 + 留白（约 40–48px），图标约 16px；入口图标**无常驻文字**、悬浮显示中文名称、保留 aria 名称 |
| FR-APP-23 | 应用功能栏入口行为 | 动作入口点击即执行或切换（刷新 = **只重扫重读清单**；置顶 = 切换并反映启用态，保持既有置顶锁定尺寸语义）；配置入口打开**自定义模态**（保留焦点 / Esc / 遮罩规则）；功能栏层级**不越过模态 / 抽屉**；入口忙碌时禁用并给出反馈 |
| FR-APP-24 | 应用功能栏入口顺序 | 入口**连续排列、无上下分组**；默认顺序 刷新 → 置顶 → 设置（未来 Agent 追加末尾）；宽窄**共用同一顺序**，存现有 `settings.yaml`（本机偏好，**不写清单**）；稳定入口 id、重复取第一次、未知入口隐藏且保留原槽位（仅重排可见入口）；新增未配置入口默认追加到用户顺序末尾、用户重排后保存；恢复默认清除历史顺序（含未知入口）；排序放下即原子保存，失败回滚到最后成功顺序并报错 |

**细则**：

- **默认顺序**：刷新 → 置顶 → 设置；未来 Agent 入口追加到末尾（**本轮无 Agent 实现或占位**）。
- **拖拽**：鼠标超过阈值触发拖拽，触屏长按触发；**拖拽结束不触发点击**。
- **排序交互**：窄屏顶部溢出进入「更多」菜单（**不挤压标题、不产生整页横向滚动**）；设置提供**全部可用入口**的完整排序（拖拽 / 上移 / 下移 / 恢复默认）。
- **刷新语义**：只重扫重读清单文件，**不保存 / 覆盖正在编辑的详情草稿、不重读设置、不新增文件监听**。
- **断点**：沿用现有 760px 断点（窄 ≤760px / 宽 >760px）；**已复核临界宽度附近（约 761px）**的栏位与图标呈现（见 04-current 验证）。
- **配置契约**：顺序字段与读写语义见 [02-interfaces.md](02-interfaces.md) §5（实际契约）。

## 9. Agent 协助（FR-APP-25~34，**已实现待验证**）

> 状态（2026-10-12）：**已实现**（Phase 1 + Phase 2；后端 **117 个 Rust 测试**、前端纯逻辑断言、`pnpm build` 均通过）；**已通过隔离集成复验（假 provider、零真实网络）并经用户验收通过；真实 DeepSeek 联网仍未实测**。运行命令 / 字段契约见 [02-interfaces.md](02-interfaces.md) §6。
> 联网仅 DeepSeek 原生（Anthropic 兼容）端点有官方源码，**真实联网验证尚未进行**，**不声称可用**。

| FR | 功能 | 验收判据 |
| :--- | :--- | :--- |
| FR-APP-25 | Agent 配置入口与密钥 | App Bar 提供 Agent 配置入口（默认 DeepSeek）；模型与 API Key 以**掩罩**展示、**不可回显**（仅替换 / 删除）；Key 存**系统保护存储**；可配置**结果主目录**；联网测试须**显式付费**、**不自动付费** |
| FR-APP-26 | 任务级启用与关联 | 任务右键 Agent 子菜单可**启用 / 停用**、**添加文件 / 目录**；任务 YAML 记录启用状态与关联路径；支持文件与目录、关联**原路径**；**任意文件 / 目录均可关联**、由 Agent **自主选择**读取；**关联 ≠ 授权** |
| FR-APP-27 | 设备本机授权 | 授权为**本机显式行为**；另一设备须**显式启用 Agent 执行权限**（任务 YAML 同步**不**自动授予执行权）；**移除路径即撤销后续读取**（不追溯已读）；路径失效只**提示、不猜测** |
| FR-APP-28 | 只读安全沙箱 | 只读访问、**不执行命令**、**不修改源文件**；阻止常见敏感文件 / `.git` / 应用密钥；**防链接越界**（链接不逃逸授权范围）；首次启用**告知云端发送边界** |
| FR-APP-29 | 读取计量 | 单次**文本**读取 ≤**256 KiB**、单次运行累计 ≤**5 MiB**；目录 / 文件**分页**、累计**不可绕过**（ADR-0007）；**不缩小授权范围**；不可解析资料**明确列出遗漏项并继续研究**（**不承诺全格式**） |
| FR-APP-30 | 调度与时间窗 | 仅**应用运行时**调度（**不新增托盘 / 自启 / 唤醒**）；本地时间 **00:00（含）–09:00（不含）** 启动，已启动可跨界完成；**09:00 后不再启动**；清单 / 任务按**显示顺序**处理 |
| FR-APP-31 | 执行上限与失败 | 并发 **1**、单次运行最长 **30 分钟**；**模型 / 搜索调用次数不设上限**；每 run 主循环**步数护栏上限 40**（**防失控护栏、非调用次数帽、不计入预算 / 次数统计口径**），达上限 → `failed(StepLimit)` 不重试，实际步数记入运行记录 `stats.steps`；每夜（**含首次**）最多 **3 次尝试**，仅对**临时网络 / 429 / 服务端失败**退避重试；**失败退避不阻塞其它任务**；**Key 余额 / 权限 / 配置错误→停止**；中断（非成功）**保留部分结果** |
| FR-APP-32 | 手动控制 | 子菜单提供「**立即 / 重跑**」（**绕过夜间窗口**）与「**停止**」；**手动停止不自动重试**，需显式「重新执行」；**停用或完成任务→取消当前并禁止后续调度**；停用再启用时**未成功任务入队**、**已成功仍不自动重跑** |
| FR-APP-33 | 成果与历史 | 成果输出到用户配置**主目录** / 任务 **ULID** / **时间**（+ **运行 ID**）；**独立历史**（稳定 id）；`report.md` 记录**来源清单 / 运行摘要**；详情可**查看结果**与「**打开结果目录**」 |
| FR-APP-34 | 状态与呈现 | 任务行尾**机器人图标位于 count 左侧且悬停不消失**；点详情进入 Agent 区（状态历史）；颜色：**待执行中性 / 运行靛蓝（轻忙碌）/ 成功绿 / 失败红 / 停止中性**；**停用隐藏图标但保留历史** |

**细则**：

- **步数护栏（FR-APP-31）**：每 run 主循环步数上限 **40**（`MAX_STEPS`）——**防失控护栏**，**不是调用次数帽、不参与预算 / 次数统计口径**；达到即 `failed(StepLimit)`、**不重试**；实际步数写入运行记录 `stats.steps`。
- **停止语义（FR-APP-32）**：手动停止 → **本夜不再自动重排**、需显式「重新执行」；停用 / 完成 / 删除导致的停止与手动停止**可区分**（运行记录 `stop_reason`）；停用→再启用时**未成功任务可重新入队**；**已完成任务不入队**。
- **运行记录与结果（FR-APP-33）**：结果布局 `{result_root}\{task_id}\{时间戳}_{run_id}\`，含 `report.md` + `sources.json`；运行记录本机 `%APPDATA%\com.lftan.todolist\agent\runs\{run_id}.json`；结果目录**只能由记录推导**。
- **读取限制**：仍为 ADR-0007（单次文本 ≤256KiB、运行累计 ≤5MiB、分页不可绕）。

**注**：Agent 入口位于应用功能栏、默认追加在顺序末尾（见 §8）。
