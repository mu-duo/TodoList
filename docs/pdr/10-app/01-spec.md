# 10-app 功能规格

> 定位：10-app 目标态功能规格（FR-APP-NN，逐条给验收判据）。依据：相关 ADR（0001~0005）。

## 1. 清单与任务

| FR | 功能 | 验收判据 |
| :--- | :--- | :--- |
| FR-APP-01 | 清单管理：多清单，创建 / 重命名 / 删除 / 排序 | 侧栏操作后 `lists/` 下文件同步创建 / 改名 / 删除，`order` 写入；重启后状态保持 |
| FR-APP-02 | 任务基础：新建 / 编辑（标题、备注）/ 删除 / 完成与取消 | 操作即时写回文件；done 带 `completed` 时间，取消后恢复 open 且移除该字段 |
| FR-APP-03 | 子任务：一层分解，独立勾选 | 子任务状态独立持久化（已实现）；父任务显示子任务进度（**已实现**：任务行尾 `已完成/总数`，悬停换成删除按钮；触屏并排、计数在 `×` 左侧） |
| FR-APP-04 | 拖拽排序与跨清单移动 | 拖拽后文件内 tasks 数组顺序同步；跨清单移动后原文件移除、目标文件出现（id 不变） |

## 2. 组织

| FR | 功能 | 验收判据 |
| :--- | :--- | :--- |
| FR-APP-05 | 标签：打 / 去标签，按标签过滤 | 标签写入 `tags`；过滤结果与文件内容一致 |
| FR-APP-06 | 优先级：高 / 中 / 低 | 设置写入 `priority`；清除后字段移除 |
| FR-APP-07 | 截止日期与时间（可选含具体时间） | 写入 `due`（`YYYY-MM-DD` 或 `YYYY-MM-DDTHH:MM`）；可清除 |

## 3. 时间

| FR | 功能 | 验收判据 |
| :--- | :--- | :--- |
| FR-APP-08 | 提醒：到点系统通知 | 到达 due（含时间）触发系统通知；触发状态可查 |
| FR-APP-09 | 重复任务（规则字段于该切片定稿） | 完成任务后按规则生成下一实例；不重复、不丢失 |
| FR-APP-10 | 逾期高亮 | 过 due 且未完成任务有标识；完成或改期后消失 |

## 4. 检索

| FR | 功能 | 验收判据 |
| :--- | :--- | :--- |
| FR-APP-11 | 搜索：按标题 / 备注 / 标签 | 输入即时过滤；结果可定位到所属清单 |
| FR-APP-12 | 智能过滤：今天 / 即将 / 全部 / 已完成 | 过滤只影响视图，不改写文件 |
| FR-APP-13 | 排序视图：截止 / 优先级 / 创建时间 | 仅视图排序，不改变文件内数组顺序 |

## 5. 桌面集成

| FR | 功能 | 验收判据 |
| :--- | :--- | :--- |
| FR-APP-14 | 托盘常驻：快速查看 / 添加 | 关闭主窗后托盘可用；快速添加写入「收集箱」 |
| FR-APP-15 | 全局快捷键快速添加 | 快捷键呼出输入，保存后任务出现在清单 |
| FR-APP-16 | 开机自启 | 设置开关生效；重启系统后自动运行 |
| FR-APP-17 | 深色模式 | 跟随系统或手动切换；重启保持 |

## 6. 历史

| FR | 功能 | 验收判据 |
| :--- | :--- | :--- |
| FR-APP-18 | 完成归档视图：已完成任务过滤视图，可恢复 | 取消完成后回到原清单且数组位置语义正确 |

## 7. 文件与外部协作（契约细节见 [02-interfaces.md](02-interfaces.md)）

| FR | 功能 | 验收判据 |
| :--- | :--- | :--- |
| FR-APP-19 | 文件即事实源：应用直接读写 YAML，无隐藏数据库 | 全部任务数据可在数据目录文件中找到；应用无私有任务数据库 |
| FR-APP-20 | 外部写入可见：外部修改文件后应用自动重载 | 外部修改保存后 ≤2s 内界面反映（当前骨架以刷新机制替代，见 04-current） |
| FR-APP-21 | agent 友好契约：稳定 ID、未知字段宽容 | 含自定义字段的文件经应用写入后字段仍在；id 不复用、不改变 |

## v1 切片范围

首个交付切片 = 核心（FR-APP-01~04）+ 搜索 / 过滤（FR-APP-11、12）+ 文件链路（FR-APP-19~21）；其余 FR 后续切片逐个交付。v1 内部再按 issue 切片推进（当前：读取-显示-回写骨架）。

**注（2026-10-10）**：FR-APP-03 **整条已实现**——「一层分解 + 独立勾选 + 状态独立持久化」+「父任务显示子任务进度」（形态＝任务行尾 `已完成/总数`；未悬停显示、悬停换成删除按钮；触屏并排且计数在 `×` 左侧）。
