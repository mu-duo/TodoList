## 关键结论与已知问题

- 冲突策略：同一任务并发修改以磁盘后写为准（ADR-0003）；极端场景可能丢一次改动（窗口极小）。
- v1 无内置备份（ADR-0003）；建议数据目录纳入 git / 网盘。
- move_list 采用整体重编号（会重写全部清单文件、YAML 排版被序列化器规范化）；功能正确，后续可优化。
- 删除任务 / 清单仅 confirm 确认、无撤销。
- 提醒 / 重复字段待对应切片定稿（02-interfaces 待决项）。
- UI 已知项：详情抽屉无焦点陷阱 / Esc；切换选中会丢弃未保存的详情草稿；新建清单后不自动选中；`created` 未在详情展示（`TaskView` 未暴露，需 Rust 侧补字段）；键盘拖拽排序未启用（未展开 dnd-kit `attributes`，需独立拖拽手柄）；触屏拖拽未设 `touch-action:none`，可能与列表滚动竞争；右键菜单无焦点陷阱 / 初始聚焦。
- 已修复（原 UI 已知项）：窄屏点复选框（及任务行）误开详情 —— 任务行改为「勾选 ｜ description ｜ 删除」三区、仅 description 触发详情。
- 排序实现注意：`reorder_list` 沿用整体重编号，会重写目录内全部清单文件（未知字段保留、无法解析文件跳过）。
- 置顶（pin）已知边界：「不可最小化」仅保证标题栏按钮置灰（`Win+↓` / `Win+M` / 显示桌面 / Alt+Space 等 OS 级路径不保证被拦）；always-on-top 盖不住独占全屏应用；跨虚拟桌面钉住在 Windows 无原生支持；置顶期间不可缩放 / 最大化；还原用的窗口状态快照仅存内存，前端重载后退化为「只解除置顶」。权限侧另需 `core:window:allow-set-always-on-top/minimizable/maximizable/resizable`（`core:default` 不含任何 setter）。
