## 关键结论与已知问题

- 冲突策略：同一任务并发修改以磁盘后写为准（ADR-0003）；极端场景可能丢一次改动（窗口极小）。
- v1 无内置备份（ADR-0003）；建议数据目录纳入 git / 网盘。
- move_list 采用整体重编号（会重写全部清单文件、YAML 排版被序列化器规范化）；功能正确，后续可优化。
- 删除：任务 / 子任务**直接删**（无确认）；**清单删除用自定义确认模态**（默认焦点在「取消」，`Esc` / 遮罩 / 取消均可退）；**仍无撤销**（触屏下任务行删除图标常显，一按即删 —— 残留风险）。
- 提醒 / 重复字段待对应切片定稿（02-interfaces 待决项）。
- 应用功能栏（App Bar，FR-APP-22~24）**已实现（用户验收通过）**：宽屏最左 48px 竖栏 / 窄屏顶部图标横排；图标无常驻文字、悬浮中文名、保留 aria；直接拖拽（鼠标阈值 / 触屏长按，拖拽结束不点击）与设置内完整排序（拖拽 / 上移 / 下移 / 恢复默认）；窄屏顶部溢出收进「更多」菜单（不挤压标题、不整页横滚）；顺序共享并存 `settings.yaml` 的 `app_bar.order`（未知槽位保留、去重取首次、新入口追加末尾、恢复默认删字段）。约束保持：刷新**只重扫重读清单**（不保存 / 覆盖草稿、不重读设置、不新增监听）；动作入口即执行 / 切换、置顶保持既有锁定尺寸语义；配置入口用自定义模态并沿用焦点 / `Esc` / 遮罩规则；功能栏层级不越过模态 / 抽屉；排序放下即原子写、失败回滚到最后成功顺序并报错。
