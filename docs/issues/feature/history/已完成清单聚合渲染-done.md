# 已完成清单（聚合渲染）

> Status: doing ｜ 责任: agent ｜ 创建: 2026-10-09 ｜ 关联: ADR-0005（完成任务留原文件）；**不改文件契约**

## 背景与语义
- 「已完成」是**虚拟清单**（非文件）：聚合所有清单中 `status=done` 的任务并在此渲染；
- 沿用既有契约：完成任务仍留在原清单文件里，只是不再在普通清单中显示；
- 原清单被删除 → 其任务随文件消失，「已完成」中对应项自然消失（无需额外逻辑）。

## 完成判据
- 清单条中存在固定项「已完成」：置末、与普通清单视觉区隔、**不可重命名 / 删除 / 拖拽**、无右键菜单；
- 普通清单**不再渲染**已完成任务（过滤 `status=done`）；计数按未完成数；
- 选中「已完成」：左栏渲染所有清单的已完成任务（已完成样式），底部「新增 todo」行隐藏或禁用；
- 在「已完成」中取消勾选 → `set_task_status(原清单文件, id, false)`，任务回到原清单，并从「已完成」移除；
- 任意清单中勾选完成 → 行播放**移除动画**后从当前清单消失；取消勾选同理；
- 「已完成」计数 = 聚合的已完成数。
