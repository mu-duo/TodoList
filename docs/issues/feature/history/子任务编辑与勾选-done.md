## 共识（定案）
- **模型不改**：保持契约原样 `{ id, title, status }`——"仅一句描述"指**输入体验**，不是删字段；勾选**不新增任何文件字段**。
- **本轮做**：新增 / 删除 / **独立勾选**（status 切换）/**双击改名**，兑现 FR-APP-03 的「一层分解 + 独立勾选 + 状态独立持久化」。
- **位置**：从元信息区（只读 `dl`）**移到「标题」与「备注」之间**，成为编辑区一块；小标题**带计数**（「子任务 · n」）；**空态保留板块 + `+`**。
- **录入**：`+` → 就地输入框；回车存档后**保持打开**（连续录入）；**空内容回车 / Esc = 退出不落盘**；**失焦不存档、草稿保留**；**关闭详情丢弃未提交草稿**。
- **改名（增量 2026-10-10，翻转原「不做编辑」）**：**双击文字** → 就地输入框（预填原值、全选、聚焦）；`Enter` 保存退出；`Esc` **取消**还原；**失焦保存**（`trim` 非空时）；`trim` 后为空 → **视为取消**（保留原值、不落盘、**不删除**）；双击区域**仅文字**（标记与 `×` 不触发）；编辑态下该条**隐藏标记与 `×`**。可发现性：`.subtask-title` 悬停加**淡下划线** + `title="双击改名"`。
- **键盘优先级**：输入框内 Enter / Esc **只作用于子任务**（`stopPropagation` + `preventDefault`），**不关详情**；IME `isComposing` / `keyCode 229` 一律不触发。
- **勾选**：点 `○` / `✓` **标记本身**切换（不整行点击）；`done` 用删除线。
- **删除**：条尾 `×`，悬停显示、`hover:none` 环境常显；**不做拖拽重排**。
- **已完成任务**：其详情**同样可增删勾选改名**；**不联动**"重开任务"（不塞隐藏副作用）。
- **深度恒为 1**：任务最大一层子任务（`SubtaskView` 结构上无嵌套字段）。
- **保存**：增删勾选改名**即时写盘**（无防抖，与标题/备注的 400ms 防抖**两条独立通道**）；失败走 `actionError`。
- **后端接口**（按 id 原子操作，避免"整数组覆盖"冲掉外部并发改动）：
  - `add_subtask(list_file, task_id, title) -> Result<SubtaskView, String>`（id 用现有 ULID 生成；append 末尾；初始 `status: "open"`）
  - `remove_subtask(list_file, task_id, subtask_id) -> Result<(), String>`
  - `set_subtask_status(list_file, task_id, subtask_id, status) -> Result<(), String>`，`status ∈ {open, done}`，非法值**报错**
  - `set_subtask_title(list_file, task_id, subtask_id, title) -> Result<(), String>`，空标题**报错**（前端不传空）
  - 文本 `trim`，空拒绝；允许重复；无条数上限；未知 task / subtask id **报错**
  - 沿用「Value 级补丁 + 未知字段保留 + 原子写」；`subtasks` 存在但非数组 → **报错**（不静默覆盖）
- **任务行显示子任务计数（增量 2026-10-10，**翻转**原「不加任何进度指示」）**：行尾、**与删除按钮同一位置**——未悬停且有子任务时显示 `已完成/总数`（如 `3/5`）；**悬停时换成删除按钮**；**无 hover（触屏）时两者并排常显、计数在 `×` 左侧**。计数随详情内增 / 删 / 勾**即时同步**。FR-APP-03 的「父任务显示子任务进度」据此**取消暂缓**（spec 同步）。

## 完成判据
- 任务行尾有子任务时显示 `x/n`；悬停换成删除按钮；触屏并排且计数在 `×` 左侧；增 / 删 / 勾后计数即时更新。
- 详情面板「标题 ↔ 备注」之间出现「子任务 · n」板块，`+` 可连续录入、回车即落盘。
- 点标记可 `open ↔ done` 往返，重启后保持；`done` 有删除线。
- 悬停 `×` 删除并即时落盘；空 / 纯空白不产生条目。
- **双击文字可就地改名**：`Enter` 落盘、`Esc` 还原、失焦保存、空标题不落盘不删除；改名期间标记与 `×` 隐藏。
- Esc / Enter 在子任务输入框内**不影响**详情面板开合；中文组字期间不误触发。
- 既有只读子任务（外部写入的对象形态）能正确显示与勾选。
- `cargo test` 全绿（含新增用例）、`clippy` 干净、`pnpm build` 通过、CDP 真机验「加 / 勾 / 删 / 改」四路都真落盘。
