# 布局改版：清单条 + 窄模式

> Status: doing ｜ 责任: agent ｜ 创建: 2026-10-08 ｜ 关联: PDR 10-app（UI 结构）；修订上一「右侧边栏」条目的布局细节

共识（grilling 定案 + 三轮评审调整）：窗口最小宽 400；清单为可滑动「清单条」；窄屏 ≤760；任务列表为内部滚动区；**左右两栏各自完整、共同组成最终视图**；两处「新增」同为「**输入框 + 按钮**」。

## 完成判据

### 窗口
- `src-tauri/tauri.conf.json`：`minWidth: 400`、`minHeight: 600`；默认窗口 1100×720。

### 整体布局（固定视口高度）
- 页头固定；内容区为左右两栏（各自内部滚动），**共同组成最终视图**；**无跨栏底部通栏**；
- **左栏（todo 视图）** = 清单标题（固定）+ 任务列表**内部滚动区** + 底部「**新增 todo**」行；
- **右栏** = 清单条（纵向可滑动，`max-height ≈ 45vh`）+ 任务详情（占剩余高度、自身可滚）。

### 新增入口（两处样式一致：输入框 + 按钮）
- 左栏底部「新增 todo」：输入框 + 「+」按钮，作用于当前清单；无选中清单时禁用占位；
- 清单条底部「新增清单」：输入框 + 「+」按钮（**同款样式**），回车 / 点击提交。

### 窄屏（≤ 760px）
- 单列：横向可滑动清单条 → 任务列表（内部滚动区）→「新增 todo」；
- 任务详情隐藏；点任务 → 右侧抽屉（可关闭），可编辑标题 / 备注。

### 不变项
- 数据契约与后端命令不动；卡片体系、warnings / error、busy 防抖、`prefers-reduced-motion`、触屏兜底保持；页头保留「刷新」。
