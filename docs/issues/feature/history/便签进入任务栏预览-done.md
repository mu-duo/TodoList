# 便签进入任务栏预览

> Status: done（2026-10-19 用户验收通过） ｜ 责任: agent ｜ 创建: 2026-10-19 ｜ 关联: 便签功能（FR-APP-35，1.8.0）后续调整；grilling 定案一轮

## 背景与目标

便签窗口创建时带 `skipTaskbar: true`（1.8.0 定案"不进任务栏/Alt-Tab"），导致 Windows 任务栏悬浮缩略图不显示便签。目标：便签出现在任务栏悬浮缩略图。Windows 没有"只进预览、不进任务栏分组"的能力，故取消 `skipTaskbar`。

## 共识（grilling 定案 2026-10-19）

- **方案 A**：取消 `skipTaskbar`，所有便签（含 pinned）**始终**进入任务栏分组（不做"跟随主窗动态切换"）。
- **托盘语义**：托盘设置开启时，只要便签存在，任务栏图标不消失（"关闭到托盘→任务栏消失"仅在无便签时成立；刻意取舍）。
- **关闭**：缩略图 X / 任务栏「关闭窗口」= 便签静默关闭丢弃（与 close 语义一致，Rust 不拦截）。
- **聚焦**：从缩略图/任务栏激活便签（窗口获得系统焦点）→ 自动聚焦文本区。
- **事实修正**：tao 用 `ITaskbarList::DeleteTab/AddTab` 实现 skipTaskbar、不影响 Alt-Tab——便签此前已在 Alt-Tab，本次不变；PDR 表述一并修正。

## 完成判据

- 任务栏悬浮 app 图标 → 缩略图包含每张便签；点击缩略图能激活对应便签且文本区已聚焦、可直接输入。
- 缩略图 X / 任务栏窗口列表「关闭窗口」→ 便签关闭丢弃、无提示、无残留窗口。
- 托盘开启 + 便签存在 → 关主窗后任务栏图标仍在（方案 A）；托盘「退出」原生确认链路不受影响。
- Alt-Tab 行为不变（本就包含便签）。
- 验证：`npx tsc --noEmit`、`pnpm build`；用户 dev 冒烟；PDR 同步（01-spec §10 / 02-interfaces §8 / 04-current）。

- 便签进入任务栏分组（取消 `skipTaskbar`）：任务栏悬浮缩略图 / 窗口列表可见；缩略图 X 与「关闭窗口」走默认关闭（静默丢弃）；从缩略图激活自动聚焦文本区；托盘开启且便签存在时任务栏图标保留（方案 A）。
- 实现：`src/noteWindow.ts`（移除 skipTaskbar）、`src/NoteApp.tsx`（`onFocusChanged` 聚焦文本区）。无 Rust / 权限变更。
