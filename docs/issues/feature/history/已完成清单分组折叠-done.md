## 背景与目标

「已完成」视图目前是跨清单平铺、无排序，来源仅靠行内「来自 X」标签。改为按来源清单分组展示、组可折叠；组内按完成时间倒序。

## 已对齐范围（2026-10-13 grilling 定案）

- 分组：按来源真实清单分组，组顺序 = 清单条顺序（order → 名称）；空组不显示；仅一个来源时也显示组头（布局一致）。
- 组内排序：`completed` 时间倒序；缺失该字段时回退文件内顺序（稳定排序）。
- 组头：清单名 + 完成数量（如「工作 · 12」），整行点击切换折叠；含 `aria-expanded` 等基础可访问性。
- 折叠状态：默认全部展开；折叠集合持久化到应用配置目录 `settings.yaml`（键 = 清单文件名）；清单重命名 / 删除后原键失效，回退展开。
- 分组视图内隐藏行内「来自 X」标签（来源由组头承载）；行内其余样式与功能（勾选取消完成、右键菜单含「移动到清单」）不变。
- 不做「全部展开 / 收起」按钮、不做组头吸顶（后续按需）。

## 完成判据

- 已完成视图按来源分组：组顺序、组内倒序（缺失回退）、数量正确；空组不出现；行内来源标签隐藏。
- 折叠交互可用（点击组头整行切换），状态持久化且重启后保持；重命名 / 删除清单后该组回退展开。
- 既有行功能不回退：取消完成后回原清单且数组位置语义正确（FR-APP-18）、右键菜单可用。
- Rust settings 测试（镜像 `app_bar_order` 模式）、`pnpm build`、可提取的纯逻辑断言通过。
