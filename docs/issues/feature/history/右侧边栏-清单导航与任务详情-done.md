# 右侧边栏：清单导航 + 任务详情

> Status: doing ｜ 责任: agent ｜ 创建: 2026-10-08 ｜ 关联: PDR 10-app（FR-APP-01/02、19~21；UI 结构）

用户要求：新增右侧边栏，分上下两部分——上：**清单列表**（点选切换清单）；下：选中 todo 的**详细信息**（可编辑）。

## 完成判据

- 布局改为「主区 + 右侧边栏」两栏；主区只显示**当前选中清单**的任务（含该清单的「新建任务」输入）；
- 侧栏上半 = 清单导航：点选切换当前清单（高亮当前项）；清单的 新建 / 重命名 / 删除 / ↑↓ 收进侧栏；
- 侧栏下半 = 任务详情（**可编辑**）：标题 / 备注可改并保存（复用 `update_task`）；状态 / 优先级 / 截止 / 标签 / 子任务 / 时间 / id 只读展示；
- 选中态：点击任务卡片 → 选中并在详情面板显示；勾选复选框仍为完成 / 取消；刷新后选中项若仍存在则保持，否则回落；
- 未选清单 / 未选任务有各自空态提示；
- 既有功能不回退：新建 / 编辑 / 删除任务、清单操作、刷新、warnings / error、busy 防抖；
- `pnpm build` 通过；dev 无行为回归。

## 边界（本切片不做）

- 优先级 / 截止 / 标签 / 子任务的**编辑**（面板内先只读，留作后续切片）；
- 移除卡片内联编辑与卡片上的「编辑」按钮（编辑迁入详情面板）；卡片右侧悬浮仅保留删除。
