# 删除交互调整：图标化 + 去掉 web 确认框

> Status: doing ｜ 责任: agent ｜ 创建: 2026-10-10 ｜ 关联: `docs/pdr/10-app/04-current.md:24`（「删除任务 / 清单仅 confirm 确认、无撤销」）

## 需求（用户）
1. 删除按钮由**文字**改为**图标**（垃圾桶）。
2. 删除**不再弹 web 确认框**。

## 现状（@explorer 核实）
- 删除入口共 4 处：**A 任务行**（`src/App.tsx:1044-1055`，文字按钮 `.row-action.danger`「删除」）、**B 子任务**（`:1237-1246`，`×` 图标，已无确认）、**C 清单删除**（右键菜单文字项 `:1357-1362`）、D 详情「关闭」（非删除）。
- `window.confirm` 仅 2 处：**删任务** `:831`、**删清单** `:863`。
- **删清单** = `delete_list` → `src-tauri/src/storage.rs:624-630` `fs::remove_file` **物理删除**（无备份 / 无撤销 / 无回收站）；**删任务** = 从数组移除 + 原子写。
- 图标风格基线：`24×24 viewBox` + `fill="none"` + `stroke="currentColor"` + `strokeWidth="1.8"` + round cap/join + `aria-hidden`（图钉 `:1419-1431`、齿轮 `:1440-1452`），尺寸由 class 控制（`.pin-icon / .settings-icon { 16px }`）。
- 行内按钮悬停显形：`src/App.css:535-554`（触屏 `@media (hover:none)` 常显 `557-578`）。

## 共识（定案）
- **图标＝垃圾桶**（经典 outline），对齐既有内联 SVG 风格（24×24 / 1.8 / currentColor / aria-hidden）、16px；按钮加 `aria-label="删除任务"` / `title`。
- **任务 + 子任务：直接删，无确认**（行内按钮悬停显形、位置固定、图标小；`onPointerDown` 已 `stopPropagation`）。
- **清单删除：保留确认，但改为「自定义确认模态」**（不再用 `window.confirm`）——与设置模态同风格：遮罩 + 卡片；**默认焦点落在「取消」**（安全默认）；`Esc` / 点遮罩 / 点「取消」均取消；`Tab` 在模态内循环；确认按钮用**危险红**；文案写明「将一并删除其中的任务，且**无法撤销**」。
- **右键菜单里的「删除」保持文字**（菜单项本就该有文字标签）。
- **不做撤销**（用户明确）；防误删靠「悬停显形 + 图标 + 位置固定」。
- ⚠️ **残留风险（记录在案）**：**触屏**下任务行删除图标常显且无确认 → 一按即删且无撤销；如日后误删困扰，可加长按确认。

## 完成判据
- 任务行删除入口是**垃圾桶图标**（非文字），视觉与既有行内按钮一致，带 `aria-label` / `title`。
- 删任务**不再出现 web 确认框**，点击即删并即时落盘。
- 删清单弹**自定义确认模态**（符合当前风格）：`Esc` / 点遮罩 / 点「取消」均取消；确认后才 `delete_list`。
- 子任务删除、右键菜单「删除」文案、勾选 / 详情 / 拖拽 / 行尾计数均无回归。
