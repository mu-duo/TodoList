# 任务与清单管理补全

> Status: doing ｜ 责任: agent ｜ 创建: 2026-10-08 ｜ 关联: PDR 10-app（01-spec FR-APP-01/02）、ADR-0002 / 0003

补齐日常使用所需的任务与清单操作：任务的 新建 / 编辑（标题、备注）/ 删除；清单的 创建 / 重命名 / 删除 / 排序。全部操作即时写回文件（Value 级补丁 + 原子写，未知字段保留）；文件名规整化处理非法字符与重名冲突。

## 完成判据

- 任务：界面可新建（追加到所在清单末尾，自动 ULID `id` 与 `created`）、编辑标题 / 备注、删除（需确认）；全部即时写回、未知字段保留；
- 清单：创建 / 重命名 / 删除（需确认）；重命名同步文件名与 `name` 字段；删除清单同时删除对应文件；
- 清单排序：界面可调（上 / 下移），写入 `order`；
- 文件名规整化：非法字符处理、重名冲突自动后缀；
- 存储层测试覆盖新增操作回环与未知字段保留；`cargo test` / 构建 / dev 冒烟通过。
