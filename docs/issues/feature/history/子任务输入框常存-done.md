# 子任务输入框常存

> Status: done ｜ 责任: agent ｜ 创建: 2026-10-14 ｜ 关联: PDR `docs/pdr/10-app/01-spec.md`（FR-APP-03）、`04-current.md`；前序归档「子任务编辑与勾选-done」

现状：详情面板子任务区为「头部 `+` → 点击后才出现输入框」。用户要求输入框**常存**（类似底部「新增任务」输入）。2026-10-14 grilling 定案如下。

## 已对齐共识（2026-10-14 grilling）
1. **形态（选 A）**：子任务列表**末尾**常存单行输入框（0 个子任务也显示），占位「新增子任务…」；**移除头部「+」**；不做固定悬浮。
2. **键盘与焦点**：Enter＝提交并清空、保持焦点（连续录入）；空/纯空白回车＝无操作；失焦不提交、草稿保留；Esc＝清空草稿、**不关详情**（输入框内事件不冒泡）；IME 合成回车不提交；打开详情不自动聚焦；关闭详情 / 切换任务丢弃未提交草稿（沿既有语义）。
3. **范围**：只做输入框常存（连带 `+` 去留与键盘语义）；子任务行渲染 / 布局不动；其他渲染问题另行开条目。
4. **已完成任务 / 已完成视图**：行为不变（同样常存输入框、可增删）。
5. **版本与交付**：暂不 bump 版本号、暂不提交；随后续功能一起推送（届时定版本）。
