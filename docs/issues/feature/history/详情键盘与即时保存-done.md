## 共识（用户明确：**改动立即落地、不存在脏标记**）
- 详情改为**即时保存**：输入防抖 ~400ms 落盘；失焦 / Esc / Enter / Ctrl+Enter 时**立即落盘**兜底。
- **移除「保存」「复原」按钮**（与"无脏标记"矛盾）。
- **空标题不落盘**：trim 后为空则不写盘、保留磁盘原值；关闭时输入框**回填**原值。
- **键盘**：`Esc` = 关闭（此刻已保存）；标题输入框 `Enter` = 保存并关闭；备注 `Enter` = 换行、`Ctrl+Enter` = 保存并关闭；**设置面板 `Esc` = 关闭**。
- 中文 IME 组合态（`isComposing`）期间**不触发**快捷键；快捷键只在详情 / 设置**激活时**生效，**不劫持全局**（不得影响"新增任务"的 Enter）。
- 清单重命名**保持**原有显式「保存」（不扩散）。
