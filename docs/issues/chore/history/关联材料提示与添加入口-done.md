# 关联材料：提示信息收敛与添加入口优化

> Status: done ｜ 责任: agent ｜ 创建: 2026-10-22 ｜ 关联: 关联材料独立板块与打开、关联链接供Agent抓取

## 背景与目标

「关联材料」板块里有两处低价值文案（空态「暂无关联材料」、底部「本地路径与链接都会提供给 Agent…」），并且三个添加入口是左对齐的纯文字按钮，可点击感弱。目标：删掉常驻文案、把「会提供给 Agent」改为悬浮提示；三个添加入口改为整行铺开、具备明确可点反馈。

## 完成判据

- 空态与底部说明文案全部删除（板块内不再有常驻说明文字）；
- 「本地路径与链接都会提供给 Agent 只读访问（链接仅支持 http(s) 抓取）」以原生 tooltip 形式挂在「关联材料」标题行上（指针悬浮可见）；
- 添加文件 / 添加目录 / 添加链接三个入口在同一行内等分铺满，具备可点击外观（+ 号、边框、hover/focus 反馈），不再是左挤的纯文字按钮；
- 「添加链接」的内联输入、校验与报错行为不变；
- 材料行与移除按钮行为不变；
- `pnpm build` 通过。
