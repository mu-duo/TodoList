# 首个分发版本 1.0.0（构建与发布操作）

> Status: doing ｜ 责任: agent ｜ 创建: 2026-10-09 ｜ 关联: grilling 定案；@librarian 事实核证（Tauri 2 分发）

## 共识（grilling 定案）
- **形态**：免安装裸 exe ＋ **NSIS 安装包**（安装器默认当前用户、无需管理员、装到 `%LOCALAPPDATA%`，缺 WebView2 会自动联网装）；不出 MSI/WiX。
- **WebView2**：沿用默认 `downloadBootstrapper`；裸 exe 缺运行时**交给 Tauri 自带原生弹框**（零自写代码）。
- **版本**：三处（`tauri.conf.json` / `package.json` / `Cargo.toml`）统一 **1.0.0**；窗口标题显示 `TodoList 1.0.0`（Rust 侧取 `package_info().version`）。
- **图标**：换正式图标（@designer 候选 → 用户挑选 → `pnpm tauri icon` 生成全套）；产品名保持 `TodoList`。
- **签名**：**不签名**，提供 SHA256；文档写明 SmartScreen「未知发布者」。
- **首次运行**：保留示例数据（现状不变）。
- **交付**：产物收集到 `release/`（入 `.gitignore`），命名 `TodoList_1.0.0_x64-setup.exe` / `TodoList_1.0.0_x64.exe` + 各一份 `.sha256`；由用户 push tag 并上传到 GitHub Release（本机无 `gh`）。
- **不做**：MSI/WiX、代码签名、GitHub Actions、自动更新（updater）、`fixedRuntime`。

## 完成判据
- 三处版本 = 1.0.0；`bundle.targets = ["nsis"]`；窗口标题带版本。
- `docs/RELEASE.md`（前提 / 步骤 / 坑）+ `scripts/build-release.ps1`（版本同步 → 构建 → 收集改名 → SHA256）+ README 增补。
- `pnpm tauri build` 产出 NSIS 安装器 + 裸 exe，且被脚本收集进 `release/` 并生成校验和。
- 新图标替换 `src-tauri/icons/`（替换掉默认 Tauri 图标）。
- 本地 `v1.0.0` tag 指向 1.0.0 的提交（push 与产物上传由用户执行）。
