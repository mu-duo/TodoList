> Status: done ｜ 责任: agent ｜ 创建: 2026-10-22 ｜ 关联: 布局改版-清单条与窄模式、右侧边栏-清单导航与任务详情

## 背景与目标

现状：宽屏下「清单」块位于右侧 340px 边栏的上半部分，任务详情占其下半部分（共用一列）。目标：清单条不再区分宽/窄模式——两种模式下都横向排列、都位于任务列表上方（左栏），右列只保留任务详情。即「宽模式 = 窄模式 + 任务详情」。

## 完成判据

- 宽屏：左栏自上而下为「清单条（横向 chip 行 + 新建清单行）」→「任务列表」；右列为任务详情，占据整列高度；
- 清单条的渲染与窄模式完全一致（横排、可横向滚动、无标题栏、项宽上限 200px、「已完成」固定项竖分隔线、`+` 行在下方）；拖拽排序轴恒为 horizontal；
- 窄屏：布局与现状一致（清单条 → 任务列表，详情为右侧抽屉）；
- 宽屏右列宽度保持 340px，详情面板样式不变；
- 既有功能不回退：选中任务详情、抽屉开关、跨清单拖拽落点高亮、清单右键菜单；
- `pnpm build` / 类型检查通过；dev 下宽窄两态冒烟正常；
- `docs/current/app.md` 与 `src/App.css` 头部布局契约注释同步。
