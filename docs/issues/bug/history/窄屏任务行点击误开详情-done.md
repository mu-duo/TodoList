## 现象
- 窄屏（≤760）点击任务行任意位置都会弹出详情抽屉；勾选完成复选框（事件冒泡）也会顺带弹出，不符合预期。

## 期望
- 任务行固定横向三区：**完成勾选框 ｜ description ｜ 删除键**；
- 仅点击 **description** 才弹出（窄屏）/ 选中（宽屏）任务详情；
- 勾选、删除各自独立（`stopPropagation`），不触发详情；
- 点行内空白无副作用；两个模式行为一致。
