# 已删除的清单缺少右键「彻底删除」

> Status: done（用户验收通过 2026-10-29） ｜ 责任: agent ｜ 创建: 2026-10-29 ｜ 关联: FR-APP-37、`docs/product/10-app/01-spec.md`

## 背景

「已删除」视图中，任务行右键可「彻底删除」，但**已删除的清单**行只有「恢复」按钮，右键没有菜单，无法立即真删除，只能等 24 小时自动清理。后端 `purge_trash_entry` 已支持 `lists` 条目，缺的是 UI 入口。

## 完成判据

- 「已删除的清单」每一行支持右键菜单「彻底删除」。
- 选择后弹确认框，文案明确「清单及其中的 N 个任务将被永久删除，无法恢复」。
- 确认后调用 `purge_trash_entry`，条目立即消失；失败显示错误。
- 原有恢复按钮、任务行右键、分组折叠、窄屏布局不回退。
