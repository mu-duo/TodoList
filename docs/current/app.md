# 10-app 现状

> 关联：[PRD 10-app 模块](../product/10-app/00-README.md)

基线继承 [00-README.md](00-README.md)：**v1.11.2（2026-10-30）**。

## 实际能力

- **清单与任务（FR-APP-01 / 02）** — 清单创建 / 重命名 / 删除 / 排序；任务新建、编辑标题与备注、完成 / 取消、删除；操作即时写回 YAML。**删除任务 / 清单为软删除**：移入「已删除」保留 24 小时，可单项恢复，到期自动永久删除（FR-APP-37）。**新建任务插入到所在清单顶部**（`tasks[0]`），跨清单移动仍落在目标清单末尾。宽屏支持双击任务内容行内编辑，右键菜单同入口；Enter 提交、Esc 取消、失焦提交，空值还原。
- **子任务（FR-APP-03）** — 任务下一层分解，可增 / 删 / 独立勾选 / 双击改名；任务行尾显示 `已完成/总数`，悬停切换为删除按钮。
- **排序与跨清单移动（FR-APP-04）** — 拖拽调整清单内任务顺序；右键「移动到清单 ▸」或拖拽到「清单条」可跨清单移动，落点为目标清单末尾，保留 id 与未知字段。仅普通视图可拖拽，已完成视图只读。拖拽离开源任务列表区后浮层收缩为 32px 首字图标，避免遮挡清单名与落点高亮；拖到「已完成」等同勾选完成。
- **删除回收站（FR-APP-37）** — 任务 / 清单删除后移入数据目录保留文件 `lists/.trash.yaml`（不是清单，加载 / 排序 / 示例检测均跳过），保留任务全部字段、原清单文件名 / 显示名与删除时间；清单删除保存整份清单内容。侧栏「已删除」固定入口（与「已完成」同级，不可重命名 / 排序 / 普通删除）按来源清单分组，任务行与普通任务卡同宽、右侧固定剩余时间与「恢复」（窄屏也不换行），点击任务行打开只读详情（恢复后可编辑），任务行右键「彻底删除」经确认后立即真删除；来源清单分组可折叠（除无时间标签外与「已完成」一致），折叠集合存 `settings.yaml` 的 `trash.collapsed`。删除的清单单独成组显示名称 / 任务数 / 「恢复」，同样支持右键「彻底删除」（连同其中任务立即永久删除）。恢复任务回原清单末尾；原清单不存在时提示选择目标清单；同 id 冲突报错不写盘。恢复清单重建文件，文件名冲突自动改用不冲突名。`deleted + 24h ≤ now` 自动真删除（启动、每 10 分钟后台、每次读取回收站时清理）；无法解析删除时间的条目保留；空回收站删除保留文件。子任务删除不进入回收站。
- **已完成视图（FR-APP-18 / FR-APP-36）** — 聚合各清单的已完成任务，仍保留在原文件；按来源清单分组、组内按 `completed` 倒序、组头「名称 · 数量」可折叠；折叠集合存 `settings.yaml` 的 `completed.collapsed`。每个来源清单内再按完成时间分「今天 / 七天内 / 更早」三档（今天＝本地自然日；七天内＝昨天至第 7 天前；更早＝第 8 天前及更早；缺失 / 无法解析归「更早」；跨天懒重算）。已完成任务可归档（任务字段 `archived`，不移动不改 `status`）；面板头部「显示归档」开关默认关、存 `settings.yaml` 的 `completed.show_archived`，关闭时不渲染归档项且计数不含；归档项沉在各时间档末尾、弱化显示并带「已归档」角标，不显示完成复选框。任务右键「归档 / 取消归档」，清单右键可批量归档该清单未归档的已完成任务，批量归档有 5 秒单槽位撤销提示。任务与清单右键菜单按区分隔，「删除」独立成区。
- **详情元数据与键盘（FR-APP-06 / 07）** — 优先级高 / 中 / 低 / 清除；截止日期可带具体时间；详情即时保存（无脏标记）；Esc 关闭、Enter 保存并关闭、备注 Ctrl+Enter。任务卡片按优先级描边：高红 / 中黄 1px，低与无优先级不加，完成 / 归档 / 选中态不叠加优先级色；优先级文字显示在卡片右侧单行，卡片过窄时隐藏。
- **任务详情结构** — 详情面板统一为七个子板块：标题、任务属性、子任务、备注、其他信息、关联材料、Agent 协助；每块为「标题行 + 内容」两段式，标题行整行可点、可折叠；任务属性默认收起，其余默认展开；折叠状态存 `settings.yaml` 的 `detail.collapsed`（空数组 = 全部展开）。
- **关联材料** — 详情内独立板块（位于 Agent 协助之前），含本地文件 / 目录路径与链接：路径存任务的 `agent.paths`，链接存 `agent.links`；本地路径与 `http(s)` 链接都会作为只读材料提供给 Agent（链接由 `url_read` 抓取），该说明以「关联材料」标题悬浮提示呈现，板块内不常驻文案；点击行即打开——文件 → 资源管理器定位、目录 → 打开、`http(s)` / `file` 链接 → 浏览器；行尾可移除；底部三个添加入口（文件 / 目录 / 链接）等分铺满整行；链接新增为就地输入，校验非空、≤2048 字符、无空白、须以 `http://` / `https://` / `file://` 开头且不重复。路径接受盘符与 UNC（含 WSL 的 `\\wsl.localhost\` / `\\wsl$\`），拒绝设备命名空间、共享根 / 盘符根与 WSL 内部路径；批量添加全有或全无，失败时就地在材料板报错并点名路径。
- **提醒（FR-APP-08）** — 对带 `due` 的未完成任务，默认在 due 前 7 天 / 1 天 / 1 小时与 due 时刻发送系统通知；`reminder: false` 关闭。详情勾选框与通知按钮共用同一开关。
- **深色模式（FR-APP-17）** — 亮 / 暗 / 跟随系统三态，偏好存应用配置目录 `settings.yaml`，重启保持。
- **文件与外部协作（FR-APP-19 / 21）** — 任务数据全部位于数据目录 `lists/*.yaml`，无隐藏数据库；稳定 ULID；写回保留未知字段；原子写（临时文件 + rename）。外部修改后需手动刷新（FR-APP-20 的自动 watch 未实现）。
- **应用功能栏（FR-APP-22 ~ 24）** — 宽屏最左 48px 竖栏、窄屏顶部图标横排；图标无常驻文字，悬浮显示中文名并保留 aria；鼠标拖拽 / 触屏长按排序，窄屏溢出收进「更多」菜单；顺序存 `settings.yaml` 的 `app_bar.order`，宽窄共享。
- **托盘常驻与单例（FR-APP-14 部分）** — 「关闭时最小化到托盘」默认开启，关闭隐藏到托盘、进程保活；托盘左键恢复，右键菜单「显示主窗口」「退出」；设置可关闭该行为；单例唤醒覆盖隐藏 / 最小化状态。快速查看 / 快速添加未实现。
- **Agent 协助（FR-APP-25 ~ 34）** — 9 个内置 Provider 预设 + 自定义端点；Anthropic 兼容 / OpenAI 兼容双协议；动态模型列表；搜索按 Provider 声明降级；凭据经 DPAPI 存本机、按 Provider 分槽、不回 JS。任务级启用与关联材料（文件 / 目录 / 链接）；只读沙箱、无命令执行；`url_read` 仅抓取任务授权链接（GET、单页 ≤256 KiB、超时 20s、重定向 ≤3 跳、SSRF 逐跳拒内网 / 保留地址、`file://` 走本地白名单）；单次文本 ≤256 KiB、单次运行累计 ≤5 MiB（含网页抓取字节）；仅应用运行时在 00:00–09:00 调度；并发 1、单次运行 ≤30 分钟、每夜最多 3 次尝试、主循环步数护栏 40；支持立即执行 / 重跑 / 停止；结果写入 `{result_root}\{task_id}\{时间戳}_{run_id}\`（`report.md` + `sources.json`）。
- **便签（FR-APP-35）** — 功能栏入口每次新建独立速记窗口，可多开；亮 / 暗两套各 6 档颜色按开窗序轮换并随主题实时重映射；无边框、可缩放、可置顶（默认关）；进入任务栏分组；关闭或应用退出即丢弃，不持久化；退出应用时存在便签会先确认。
- **布局** — 宽屏两栏：左列自上而下为「清单条 → 任务列表」（任务列表内部滚动），右列只有任务详情（340px、占满整列高度）；窄屏单列，清单条在宽窄两态渲染一致（横排 chip + 新建清单行、无标题栏），任务详情为右侧抽屉。
- **分发** — NSIS 安装包 + 免安装裸 exe；1.11.1 产物已构建（安装包 3.03 MB / 裸 exe 8.55 MB）。

当前未提供：标签（FR-APP-05）、重复任务（FR-APP-09）、逾期高亮（FR-APP-10）、搜索 / 过滤 / 排序视图（FR-APP-11 ~ 13）、全局快捷键（FR-APP-15）、开机自启（FR-APP-16）、托盘快速查看 / 添加（FR-APP-14 剩余部分）、外部变更自动重载（FR-APP-20 的 watch）。

## 关键行为与限制

- **并发与外部写入** — 同一任务被应用与外部同时修改时，以磁盘后写为准，不做字段级合并；极端场景可能丢一次改动。写回采用重读-补丁-原子写，未知字段保留。v1 无内置备份，建议数据目录纳入 git / 网盘（[外部写入与写入安全](../adr/0003-外部写入与写入安全.md)）。
- **清单重排与移动** — `move_list` / `reorder_list` 采用整体重编号，会重写目录内全部清单文件，YAML 排版被序列化器规范化；无法解析的文件跳过。跨清单移动先向目标追加、再自源移除；源移除失败时回滚目标，回滚失败会明确报「可能双份」。
- **删除与撤销** — 任务 / 子任务直接删除、无确认；任务与清单删除移入「已删除」并保留 24 小时，可单项恢复，到期永久删除；清单删除仍使用自定义确认模态（默认焦点在「取消」）。子任务删除与 24 小时之外的删除无撤销。
- **提醒边界** — 仅基于完整快照运行；清单读取不完整（目录 / 文件错误、无效 YAML、任务项被跳过等）时全局 fail closed，暂停发送并保留 checkpoint，完整刷新后恢复。启动 / 手动刷新同步快照，无文件 watcher。首帧静默处理已过的提前档，到期档补一条；应用关闭期间完整发生的 open→done→open 无法识别。通知「不再提醒」按钮仅在通知停留屏幕时有效（Windows Tier 1 限制）；通知为 best effort，无提醒状态面板。
- **任务行内编辑** — 宽屏双击内容区或右键「编辑」进入；编辑中该行拖拽临时禁用；详情同屏时草稿同步，避免旧值回写。
- **便签** — 关闭即丢弃、无提示；暗色灰阶避开中灰带（#60–#98），呈 3 深灰 + 3 浅灰两族（刻意取舍）；原生退出对话框若底层 `run_on_main_thread` 失败则不再弹出（不可同步感知）。
- **托盘** — 系统关机 / 注销不拦截；托盘缺失时不隐藏，防止无恢复入口；升级时 Restart Manager 提示关闭，托盘态需先从托盘菜单「退出」（见 `docs/RELEASE.md`）。
- **Agent 已知限制** — 真实联网未实测；保存配置不预校验模型可用性（运行期 fail-closed）；`drain_once` 不复查 `execution_enabled`；混合协议（opencode-go）逐项标注未被 CDP 覆盖；结果写出未跨写持目录句柄（低危 TOCTOU）；`agent_start_task` 去重 `check→enqueue` 非原子（低危）；手动停止标记写失败时 fail-open（低危）；停用 / 完成 / 删除的在途取消为每步检测而非即时中断；`probe` 真取消未实现。
- **UI 已知项** — 详情抽屉无焦点陷阱（Esc 已支持）；新建清单后不自动选中；`created` 未在详情展示；触屏拖拽未设 `touch-action:none`，可能与列表滚动竞争；右键菜单无焦点陷阱 / 初始聚焦。
- **升级** — NSIS 默认「先卸载再安装」，可选「Do not uninstall」原地覆盖；不支持降级；运行中应用由 Restart Manager 检测。
