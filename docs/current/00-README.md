# 现状文档集（Current）

描述产品**当前实际**的能力、关键行为与限制，并给出各项结论相对**基线**的验证信心。与 [产品 PRD](../product/00-README.md) 平级、互相独立；本集不写任务日志 / 待办 / 计划中的能力，是唯一的状态来源。

PRD 描述产品目标与方案；SPEC 是实现事实标准；本集只记现状。

## 基线

**v1.10.1（2026-10-28，tag v1.10.1）**。本集结论对应该 tag 的代码与构建产物。

基线在本文件声明一次，各模块 / 主题文件默认继承，无需逐条重复举证。个别文件基于不同基线时在该文件单独覆写并在下方索引注明。验证信心同理：默认口径在此说明，只有例外才逐条标注。

## Current 维护

- 由编码 agent 在 issue 收尾时更新事实；编排者 review diff。
- 同步只跟随**选定基线**：只记录已包含在该基线内的变更；尚未进入基线的改动不写入。
- issue 收尾时检查变更是否已包含在选定基线：是则更新受影响的 Current 文件（只改事实，不插入指向 issue 的自链接或任务历史）；否则不更新，在 issue 记一条待同步项。
- 基线前移时刷新受影响的 Current 文件（无自动化 / 钩子，属评审动作）。
- 实际状态未变则不改动。

## 与 PRD / SPEC 的关系

- PRD = 产品目标与方案（宏观叙事），SPEC = 实现事实标准，本集 = 实际形态；PRD 与本集两棵树各自可读、互不内嵌，PRD 不是事实源。本集只记现状，且是唯一的状态来源。
- 两边的模块 / FR 用链接关联（语义 / 导航 / 契约链接皆可），多对多，不强制逐文件对应；本集可以链接到 PRD / SPEC / ADR，PRD 不反向链接到本集。
- 需要指向某项决策时，用描述性短语 + 指向稳定 ADR 文件的普通 Markdown 链接（例：支持 [外部写入](../adr/0003-外部写入与写入安全.md)）；不转述 ADR 理由，ADR 链接可选、不自动推断。
- 对照 SPEC 与实际得到的是**候选**任务，供用户挑选；差异不都是缺失功能（可能是漂移 / 质量 / 未验证 / 目标过时）。

## 新增模块 / 主题

- 在本目录按需新增 `<模块>.md` 或主题文件（不强制编号对齐 PRD）；
- 在上方索引与阅读顺序登记入口；基于不同基线的文件在此注明；
- 结论默认继承本文件基线；仅当该文件基线不同或验证信心有例外时单独说明。
