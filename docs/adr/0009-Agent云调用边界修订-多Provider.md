# Agent 云调用边界修订：多 Provider

ADR-0005 划定「Windows 单机本地、无账号、无内置云同步」边界；ADR-0008 为其开出一个**受控云调用例外**，但将该例外**限定于 DeepSeek 原生（Anthropic 兼容）端点**。本 ADR **修订 ADR-0008 的 provider 限定条款**：例外范围从「仅 DeepSeek 原生端点」扩展为**多 Provider**，并沿用 ADR-0008 的全部安全与边界约束。ADR-0005 的「无账号 / 无内置云同步 / 无内置备份」条款**继续有效**；ADR-0008 中除 provider 限定外的其余条款**继续有效**。

## Provider 与端点（**修订 ADR-0008 的 provider 限定；其余约束不变**）

- **协议（双协议）**：支持两种兼容协议——**Anthropic Messages 兼容**与 **OpenAI 兼容**。
- **端点来源**：**内置预设官方端点 + 用户自定义端点**。自定义端点**协议可选、`baseURL` 可配、Key 可空**（允许无 Key 的本地 / 自建端点）。
- **风险自担**：自定义端点为**用户自有配置**，其行为与后果**由用户自担**（本应用为**本地单机应用**，用户对自己配置的端点负责）。**非 https 端点且带 Key 时，UI 轻提示**（不阻断）。
- **搜索能力降级**：搜索能力**按 provider 声明降级**，**仅声明支持者启用**；**不引入第三方搜索服务 Key**；搜索仍走**独立请求**（服务端工具 `web_search_20250305`），**不与客户端只读 fs 工具混用**（沿用 ADR-0008）。

## 保留条款（**沿用 ADR-0008，不变**）

- **模型**：**不自动回退**到其它模型；不支持的模型明确报错。
- **费用**：**不自动付费**；付费探测仅在用户**显式二次确认**后发起。
- **重定向**：HTTP **禁跟随重定向**（3xx＝失败）。
- **结果判定**：检索结果 / 引用为**不可信数据**，**绝不执行**。
- **步数护栏**：每 run 主循环步数上限 **40**（`MAX_STEPS`，防失控护栏，**非次数帽**）。
- **沙箱**：只读沙箱**无 exec / 不改源文件**。
- **凭据**：系统保护密钥（DPAPI）**不可回 JS**；本次**分槽化**——**每 provider 一槽**，旧**单槽自动迁移**。
- **首次启用告知**：首次启用须告知**云端发送边界**，文案**泛化为「所选 provider」**（不再特指 DeepSeek）。
- 其余配套约束（配置与结果目录、读取计量 ADR-0007 等）沿用 ADR-0008。

## 未实测限制（**不得据此声称可用或已验收**）

- 内置预设与部分**第三方兼容端点**的行为**仅有第三方文档依据**，**未实测**。
- 沿用 ADR-0008 的既有未实测项（`text.citations` 文档与实现不一致、`server_tool_use` 解析分歧、`max_uses` 语义与错误码未文档化、服务端与客户端工具混用无官方确认、无独立 `web_search` REST 规范）及「真实联网未实测」口径。
- 系统保护、无 exec、输出目录安全等为**冻结规范**，**未经运行验证**。

## 代价

- 应用网络出口从「单一固定官方端点」变为「**可配置端点集合**」，**风险面扩大**：用户配置的 `baseURL` 使**密钥可能随用户所配端点外发**（含非 https / 第三方端点），密钥流向不再由应用单方限定。
- **验证链变长**：多协议 × 多端点 × 搜索能力声明差异，需对每条组合分别判定，验证成本高于单端点。
- **预设端点漂移**：内置预设依赖第三方端点的协议稳定性与官方文档，**第三方变更 / 漂移**可能使预设失效，需持续跟踪。
- 网络行为的验证与合规成本由该功能承担；用户自定义端点的行为边界由用户负责，应用不代为担保。

## Considered Options

- **维持仅 DeepSeek 原生端点（ADR-0008 原状）**：与用户多 Provider 需求冲突。
- **仅让用户自配第三方代理**：ADR-0008 已否决（验证链更长、不满足需求）；本 ADR 改为**显式支持自定义端点并声明风险自担**，而非依赖未声明的代理。
- **引入统一网关 / 内置第三方搜索服务**：超出范围、引入额外服务与 Key，拒绝。
- **不做搜索能力降级、对所有 provider 一律启用搜索**：对未声明支持者会静默失败或误判成功，拒绝。
