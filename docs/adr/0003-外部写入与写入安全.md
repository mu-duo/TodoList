# 外部写入与写入安全策略

app 与外部（agent / 手改）双向修改同一文件。约定：app 写回采用「重读最新文件 → Value 级补丁只改目标字段 → 原子写（临时文件 + rename）」；未知字段一律保留；文件变更时 app 自动重载；同一任务并发修改以磁盘后写为准（不做字段级合并，已知限制）；v1 不做应用内备份。

代价：极端并发下可能丢一次改动（窗口极小：app 操作即时保存）；数据丢失防护交由 git / 网盘承担。

## Considered Options

- **文件锁 / 单写者仲裁**：实现复杂，且无法约束外部手改与 agent。
- **字段级合并（如 CRDT）**：个人规模不值当，需要时再议。
