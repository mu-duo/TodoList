# 设置存储：应用配置目录下的 `settings.yaml`

非任务类的应用偏好（当前只有：**主题**）单独存一份 `settings.yaml`，位置在**应用配置目录**——Windows 为 `%APPDATA%\com.lftan.todolist\settings.yaml`——**不进数据目录**。YAML 格式；字段可选、**未知字段保留**、**原子写**（沿用 ADR-0003 的做法）；文件缺失 / 解析失败 → 回退默认值（`theme: system`）。

理由：数据目录是"任务数据"，用户可能把它纳入 git / 网盘做跨设备同步；把**机器相关**的偏好混进去，会在同步里制造噪音与冲突。这也正是 02-interfaces 既有分工（非任务数据不进数据目录）的延续。

代价：该目录在卸载时若用户勾选「删除应用数据」会被清掉——偏好丢失需重设一次（任务数据在 `文档\TodoList`，不受影响）；设置与任务数据分处两地，agent 无法在一个目录里看全。
