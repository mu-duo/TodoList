# 删除回收站：24 小时暂存与自动清理

删除任务 / 清单不是物理删除，而是移入数据目录内的保留文件 `lists/.trash.yaml`，保留 24 小时；期间可单项恢复，到期自动真删除。侧栏提供固定「已删除」入口（与「已完成」同级的虚拟视图），不参与清单重命名 / 排序 / 普通删除。

代价与限制：

- 数据目录多一个保留文件；外部 git / 网盘会看到已删除内容，24 小时后才消失。
- 24 小时是防误删窗口，不是备份 / 历史版本；到期后不可恢复。
- 应用关闭期间过期不清理，下次启动时补清理；运行中每 10 分钟清理一次。
- 恢复任务时原清单已不存在，需要用户选择目标清单；恢复清单时文件名冲突自动改用不冲突的新文件名。
- 子任务删除不在本决策覆盖范围内。
