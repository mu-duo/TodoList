# Agent 云调用例外：受控访问 DeepSeek 原生端点

ADR-0005 划定「Windows 单机本地、无账号、无内置云同步」边界。Agent 协助功能需要联网研究，故开一个**受控例外**：仅当用户**显式启用** Agent 且配置**系统保护**的 API Key 后，Agent 运行可向 **DeepSeek 原生（Anthropic 兼容）端点**发起网络调用；其余主体与场景仍本地优先，ADR-0005 的「无账号 / 无内置云同步 / 无内置备份」条款**继续有效**。

边界：例外**仅限 Agent 功能**、且仅在用户启用时发生；**不引入额外搜索服务 Key**；首次启用须**告知云端发送边界**；**不自动付费**联网测试；仅 DeepSeek 原生 Anthropic 兼容端点有官方源码，**真实联网验证尚未进行**（不代表可用或已验收）；本 ADR 针对**尚未实现**的 Agent。

代价：应用从「零网络」变为「有条件的网络出口」，需在首次启用、配置与结果目录、只读安全沙箱、读取计量（ADR-0007）等处配套约束；网络行为的验证与合规成本由该功能承担。

## 执行与联网取舍（Phase 1 冻结，**未实测**）

- **模型**：默认 `deepseek-flash`、可配置；**不自动回退**到其它模型（回退可能追加费用并改变行为），不支持的模型明确报错。
- **原生搜索**：联网仅走**独立辅助 Anthropic 兼容请求**（`web_search_20250305`，`max_uses` 为**单请求内**上限），**不与客户端只读 fs 工具混在同一请求**（官方未确认可混用）。
- **重定向 / 结果判定**：HTTP **禁跟随重定向**（3xx＝失败）；2xx 但**无 `web_search_tool_result` 块不得视为联网成功**；检索结果 / 引用为**不可信数据**，绝不执行。
- **次数与时限**：**无全局模型 / 搜索调用次数帽**；保留 **30 分钟 deadline / 取消 / 读取限制**（ADR-0007）。
- **费用**：不自动付费；付费探测仅在用户**显式二次确认**后发起（且本阶段未做真实调用）。
- **凭据 / 沙箱 / 输出安全**：系统保护密钥（DPAPI）**不可回 JS**、只读沙箱**无 exec / 不改源文件**、输出路径由 Rust 拼装并防链接替换——均作**规范约束**，**未声称已验证**。

## 未实测限制（**不得据此声称可用或已验收**）

- 仅 DeepSeek 原生 Anthropic 兼容端点有**官方一方源码**；**真实联网调用尚未进行**。
- 存在未决矛盾 / 未验证项：`text.citations` 文档称 Ignored 而一方实现依赖；`server_tool_use` 文档 Supported 而一方不解析；`max_uses` 语义与错误码未文档化；服务端与客户端工具混用**无官方确认**；无独立 `web_search` REST 规范。
- 系统保护、无 exec、输出目录安全等为**冻结规范**，**未经运行验证**。

## Considered Options

- **维持完全无云**：Agent 联网研究无法实现，与用户需求冲突。
- **内置云同步 / 账号**：超出范围、引入服务端与账号体系，拒绝。
- **仅让用户自配第三方代理**：不满足「仅 DeepSeek 原生」要求，且验证链更长。
