# 本地优先：纯文本文件为唯一事实源

任务数据以明文 YAML 文件存储（每清单一文件，位于用户数据目录），应用不设隐藏数据库；文件即唯一事实源，用户 / 外部 agent / git / 网盘均可直接读写与版本化。核心诉求是「数据可被外部进程读写且可版本化」，双表示（数据库 + 导出）会引入持续同步的复杂度。

代价：放弃数据库的事务与查询能力（个人规模可接受）；需自行实现原子写、文件监听与宽容解析。

## Considered Options

- **数据库为事实源 + 导出文件**：文件只是快照，外部写入难以回流。
- **数据库 + 文件双写镜像**：两套表示需持续同步，复杂度高、易漂移。
