# 技术栈：Tauri 2 + Rust 后端 + React/TS 前端

桌面壳选 Tauri 2（稳定线 2.12.x；Tauri 3 尚处 alpha 不采用）；数据 / 文件 / 冲突逻辑全在 Rust 侧，前端 React + TypeScript 仅作界面与 IPC（薄层）；包管理 pnpm。配套选型：YAML 用 `yaml_serde`（备选 `serde-saphyr`）、ID 用 ULID、文件监听用 `notify`（细节阶段）、桌面能力用官方插件（通知 / 全局快捷键 / 自启 / 单实例），托盘用核心 `tray-icon`。

代价：保留 WebView + TS 工具链（相对纯 Rust UI 略重）；前后端两侧的编排与 IPC 成本。

## Considered Options

- **Svelte / Vue 前端**：同为目标可行方案；React 由用户选定（生态最大）。
- **纯 Rust WASM 前端（Leptos / Yew）**：工具链与组件生态代价高，v1 不划算。
