# Agent 读取限制：单次文本 ≤256KiB、单次运行累计 ≤5MiB

Agent 协助任务（仍在 grilling，**尚未实现**）需只读访问任务关联的本地资料。为约束单次运行的读取量与副作用，定：**单个文本文件单次读取上限 256 KiB**，**单次运行累计读取上限 5 MiB**；目录与文件通过**分页**遍历；累计上限**不可绕过**（分页 / 多次读取均计入累计，不能靠拆分读取规避）。

本限制**不缩小授权范围**：任意已授权文件均可被关联 / 发现，由 Agent **自主选择**读取；限制只约束「单次文本读取字节」与「单次运行累计字节」，不按后缀做授权白名单。不可解析的资料**明确列出遗漏项并继续研究**，不静默跳过、不中断整体运行。

边界：**不是费用封顶**（不设费用上限、不做精确费用计量）；仅覆盖**文本**读取，**不擅自规定 PDF / 图像 / 网络请求的计量口径**；针对尚未实现的 Agent，**当前未实现**，实现前不代表任何运行时行为。联网方面仅 DeepSeek 原生（Anthropic 兼容端点）有官方源码，**真实联网验证尚未进行**，不代表可用或已验收。

理由：以固定的字节上限约束**上下文体积、内存占用与费用**（外发上下文 / 解析载入 / 模型费用），同时**不缩小只读授权**，保留 Agent 自主研究能力；把「可枚举的遗漏」显式化，避免静默丢资料。

代价：256 KiB / 5 MiB 为经验阈值，可能与个别大文件研究冲突；预留**未来复议**（读取限制是否调整、**计量口径**、是否**配置化**）。

## Considered Options

- **只设单文件上限、不设累计**：无法约束一次运行的总读取量。
- **精确字节 / 费用计量**：需引入费用口径，且用户明确不封顶费用。
- **按后缀授权白名单**：与「授权范围不缩小、Agent 自主选择」冲突。
