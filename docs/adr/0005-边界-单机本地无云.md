# 边界：Windows 单机本地，无账号与云同步

> 经 ADR-0008 修订（2026-10-12）：Agent 协助功能引入受控云调用例外；本地 / 无账号 / 无内置云同步 / 无内置备份条款不变。
> 经 ADR-0009 修订（2026-10-14）：云调用例外的 provider 从「仅 DeepSeek 原生端点」扩展为多 Provider（Anthropic 兼容 / OpenAI 兼容，预设 + 自定义端点）；本地 / 无账号 / 无内置云同步 / 无内置备份条款仍不变。

v1（及可预见版本）只做 Windows 桌面单机：无账号体系、无内置云同步、无内置备份；多设备同步由用户将数据目录放入 git / 网盘自行实现。应用单实例运行。

**例外（见 ADR-0008，经 ADR-0009 修订）**：Agent 协助功能在用户**显式启用**并配置**系统保护**的 Key 后，可受控访问**用户所选 Provider 的端点**——内置预设（官方）或**用户自定义端点**，协议为 **Anthropic Messages 兼容**或 **OpenAI 兼容**；仅此功能、仅用户启用时联网，其余场景仍本地。

代价：无开箱即用的多端同步；跨设备一致性由用户自管（换取零服务端成本与数据隐私）。
