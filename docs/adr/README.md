# ADR 规则与目录

## 规则

- 文件名：`NNNN-精炼 slug.md`（4 位零填充；**编号永不复用**：新增 = 当前最大编号 + 1，墓碑桩计入）；slug（文件名）不可变，墓碑桩化只清空内容、不改文件名；标题写在文件内 H1。
- 维护范围：**未删除**的条目（含已失效标注者）均在册；允许修改与删除，完整历史由 git 兜底。
- **语义修改**（结论 / 约束 / 范围变化）就地修改，并在条目 `## Log` 追加一行 `- YYYY-MM-DD <一句话原因>`。
- **非语义修改**（错字、格式、补链接）直接改，无需 Log。
- 默认就地改；仅当变更是"方向性 / 值得长期单独引用"时才新增条目，旧条目加注记。新增时若编号已被占用（并发写入），顺延 +1 并 sweep 更新引用。
- **删除**优先用 `> 已废弃（日期）：原因` 标注（内容保留）；仅当项目**人类 owner**（或经其明确授权）判定"无借鉴价值 / 纯噪音"时才删除，agent 不得自行判定。
- 删除 = **墓碑桩化**：文件内容清空为两行 `# <原标题>` + `> 已删除（YYYY-MM-DD）：原因`，**保留编号与文件名**；墓碑桩不再删除（编号永久退役）。
- 删除顺序：①墓碑桩化（改写文件）→ ②目录移除该行 → ③全仓库 sweep；重试 / 重跑前先核对，避免重复 Log 或注记。
- 失效标注（H1 之后，活跃条目无标注；**每个退役事件一行、可叠加**；只允许下列既定集合，不允许自由文本注记）：
  - `> 已被 ADR-XXXX 取代（日期）：一句话`
  - `> 经 ADR-XXXX 修订（日期）：一句话`
  - `> 已废弃（日期）：原因`
  - `> 已删除（日期）：原因`（墓碑桩）
- **删除或语义修改**触发引用核查：优先派 subagent，无则自行 grep `ADR-\d{4}`（范围 = 全仓库；`docs/` 必改，代码注释逐一判定：保留 / 更新 / 就地注释；逐一处理后再收尾）。引用优先改指替代 ADR 编号；无替代则删去该句或就地注明「（ADR-XXXX 已删除）」。
