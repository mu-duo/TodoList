# 存储格式：YAML，每清单一文件

清单数据用 YAML（`lists/<清单名>.yaml`）：结构化元数据表达自然、机器读写稳定、对人可读，且生态有维护中的解析库（`yaml_serde` / `serde-saphyr`）。关键 schema 约定：稳定 ULID `id`；`status: open|done`（完成任务留在原文件）；数组顺序即显示顺序；未知字段宽容（细则见 `docs/pdr/10-app/02-interfaces.md`）。

代价：YAML 有缩进与引号等书写陷阱（解析端以宽容解析兜底）；写入为整文件重写（数据量级小，可接受）。

## Considered Options

- **JSON**：机器最稳，但人读差、无注释，外部手改体验不佳。
- **Markdown 复选框**：人读最佳，但程序化写回需自定行语法、复杂元数据表达啰嗦，且整篇无损往返无成熟库。
